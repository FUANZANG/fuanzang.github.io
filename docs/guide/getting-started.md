# 快速开始

欢迎来到 FUANZANG 的个人站点！这里是我的知识库、博客和作品展示空间。

## 关于这个站点

这个站点基于 [VitePress](https://vitepress.dev/) 构建，使用 Markdown 编写内容，支持：

- **学习笔记** — 技术文章、读书笔记、知识总结
- **作品展示** — 个人项目与开发实践
- **思考分享** — 对技术和生活的感悟

## 如何使用

### 浏览内容

通过顶部导航栏可以访问不同板块：

- **首页** — 站点总览
- **指南** — 使用指南和教程
- **博客** — 文章和笔记

### 搜索

使用右上角的搜索框（快捷键 `Ctrl+K` / `Cmd+K`）可以快速搜索站点内容。

### 主题切换

支持浅色和深色两种主题，点击右上角的图标即可切换。

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run docs:dev

# 构建
npm run docs:build

# 预览构建结果
npm run docs:preview
```

## 添加新文章

1. 在 `docs/blog/` 目录下创建新的 `.md` 文件
2. 使用 Markdown 编写内容
3. 更新 `.vitepress/config.mjs` 中的侧边栏配置
4. 推送到 GitHub，自动部署上线
