# USB PD 快充协议

> 📌 本文件记录 USB Power Delivery 协议的演进、PD 3.1 EPR 240W 快充、以及实际应用。
>
> 📅 基于 2026-10 时点：USB PD 3.2（2024.10 发布）已商用，2026.3 起欧盟强制 27W+ 新项目使用 PD 3.2 认证。

---

## 1. 什么是 USB PD

USB Power Delivery（USB PD）是 USB-IF 制定的快充协议，通过 USB-C 接口传输更高功率。

> 前端类比：USB PD 就像前端的"动态导入"——设备和充电器协商最优的电压/电流组合，而不是一刀切。

---

## 2. PD 协议演进

| 版本 | 年份 | 最大功率 | 最大电压 | 最大电流 | 关键新增 |
|------|------|----------|----------|----------|----------|
| USB PD 1.0 | 2012 | 100W | 20V | 5A | 基础快充 |
| USB PD 2.0 | 2014 | 100W | 20V | 5A | 标准化 |
| USB PD 3.0 | 2017 | 100W | 20V | 5A | PPS（可编程电源） |
| USB PD 3.1 | 2021 | 240W | 48V | 5A | EPR（扩展功率范围） |
| USB PD 3.2 | 2024 | 240W | 48V | 5A | SPR AVS + EPR Peak Current，2026.3 起欧盟强制 |

---

## 3. PD 3.0 vs PD 3.1

### 3.1 PD 3.0（SPR — 标准功率范围）

| 电压 | 电流 | 功率 |
|------|------|------|
| 5V | 3A | 15W |
| 9V | 3A | 27W |
| 15V | 3A | 45W |
| 20V | 3A | 60W |
| 20V | 5A | 100W |

### 3.2 PD 3.1（EPR — 扩展功率范围）

| 电压 | 电流 | 功率 |
|------|------|------|
| 5V | 3A | 15W |
| 9V | 3A | 27W |
| 15V | 3A | 45W |
| 20V | 3A | 60W |
| 20V | 5A | 100W |
| 28V | 5A | 140W |
| 36V | 5A | 180W |
| 48V | 5A | 240W |

**关键区别**：EPR 增加了 28V、36V、48V 三档电压，功率从 100W 跃升到 240W。

### 3.3 PD 3.2 的改进（2024.10 发布）

| 特性 | 说明 |
|------|------|
| SPR AVS | 标准功率范围（27-100W）内引入可调电压源，9-20V 以 100mV 步进精准匹配 |
| EPR Peak Current | 扩展功率范围新增"峰值电流"字段，允许短时超载至 5A 以上 |
| 版本协商 | 在显式合约建立前自动检测并配对 PD 版本，避免新旧设备握手失败 |
| VDEM 框架 | 新增 Vendor Defined Message 扩展框架 |

**市场影响**：2026 年 3 月起，欧盟强制 27W 以上新项目使用 PD 3.2 认证。

## 4. PPS（可编程电源）

PD 3.0 引入的 PPS（Programmable Power Supply）允许充电器和设备动态协商电压/电流：

```
传统 PD: 固定档位（5V → 9V → 15V → 20V）
PPS: 连续可调（3.3V - 21V，步进 20mV）
```

> 前端类比：PPS 就像前端的"动态调整"——不是一次性加载所有资源，而是按需、增量加载。

**PD 3.2 的 SPR AVS**：PPS 的升级版，将可调电压从仅 EPR 扩展到标准功率范围（SPR），9-20V 以 100mV 步进，充电效率进一步提升。

**实际意义**：
- 手机充电时，充电器根据电池状态实时调整电压/电流
- 减少充电发热，延长电池寿命
- 边充边用时，充电器可以动态调整功率分配

## 5. 240W 快充的实际应用

### 5.1 笔记本充电

| 设备 | 传统充电器 | PD 3.1 240W | 充电时间 |
|------|-----------|-------------|----------|
| MacBook Pro 16" | 96W | 140W | ~1.5h → ~1h |
| 游戏本 | 180W | 240W | ~2h → ~1h |
| 轻薄本 | 65W | 100W | ~2h → ~1.5h |

### 5.2 手机充电

| 手机 | 传统充电 | PD 3.0 PPS | 充电时间 |
|------|----------|-----------|----------|
| iPhone 16 Pro | 20W | 27W | ~1.5h → ~1h |
| 三星 S25 Ultra | 45W | 45W | ~1h |
| 小米 15 Pro | 90W | 90W | ~30min |

### 5.3 多设备充电

一个 240W GaN 充电器可以同时给：
- 笔记本（100W）
- 手机（27W）
- 耳机（5W）
- 平板（45W）
- 剩余功率：63W（可再接一个设备）

## 6. GaN 充电器

GaN（氮化镓）是新一代半导体材料，用于制造更小、更高效的充电器：

| 参数 | 传统硅充电器 | GaN 充电器 |
|------|-------------|-----------|
| 体积（65W） | 大 | 小 50% |
| 效率 | 85-90% | 92-95% |
| 发热 | 高 | 低 |
| 开关频率 | 低 | 高（可缩小变压器） |
| 价格 | 便宜 | 稍贵 |

> 前端类比：GaN 就像前端的"编译优化"——同样的功能，更小的体积、更高的效率。
