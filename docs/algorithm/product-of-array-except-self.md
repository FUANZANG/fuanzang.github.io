# 除自身以外数组的乘积（Product of Array Except Self）

**难度：** Medium

## 题目描述

给你一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。

题目数据保证数组 `nums` 任意前缀或后缀的乘积都在 32 位整数范围内。

请**在不使用除法**的前提下，以 `O(n)` 时间复杂度完成算法，并且你设计的算法在只使用**常数级**（`O(1)`）额外空间的情况下完成（输出数组 `answer` 不计入额外空间）。

### 约束条件

- `nums.length == n`
- `2 <= n <= 10^5`
- `-30 <= nums[i] <= 30`
- 题目数据保证数组 `nums` 任意前缀或后缀的乘积都在 32 位整数范围内。

## 示例

示例 1：

```text
输入：nums = [1, 2, 3, 4]
输出：[24, 12, 8, 6]
解释：
  answer[0] = 2 * 3 * 4 = 24
  answer[1] = 1 * 3 * 4 = 12
  answer[2] = 1 * 2 * 4 = 8
  answer[3] = 1 * 2 * 3 = 6
```

示例 2：

```text
输入：nums = [-1, 1, 0, -3, 3]
输出：[0, 0, 9, 0, 0]
```

示例 3：

```text
输入：nums = [2, 3, 4, 5]
输出：[60, 40, 30, 24]
```

## 提示 / 解题思路

- **朴素思路**：对每个位置 `i`，把所有 `j !== i` 的元素乘起来。时间复杂度 `O(n^2)`，太慢。
- **关键观察**：`answer[i] = (i 左侧所有元素的乘积) × (i 右侧所有元素的乘积)`。
- **两次遍历法（O(n) 空间）**：
  - 从左往右扫一遍，用数组 `L` 记录每个位置左侧所有元素的乘积；
  - 从右往左扫一遍，用数组 `R` 记录每个位置右侧所有元素的乘积；
  - 最后 `answer[i] = L[i] × R[i]`。
- **常数空间优化（本题标准解）**：不需要真的开两个 `L` 和 `R` 数组。
  - 第一遍先从左到右，把「左侧乘积」直接累放进结果数组 `answer`，同时用变量 `left` 滚动维护当前左侧乘积；
  - 第二遍从右到左，用变量 `right` 滚动维护当前右侧乘积，令 `answer[i] *= right` 即可原地合并。
  - 这样只需 `O(1)` 额外变量，结果写进 `answer`（输出数组不计入额外空间）。
- **为什么不能用除法**：数组里可能出现 `0`。若用「总乘积 ÷ 自身」，遇到 `0` 直接无法计算，且多个 `0` 时逻辑会变复杂。题目要求「不使用除法」正是为此。

## 解法

两次线性扫描：第一遍从左到右把每个元素左侧的乘积写入结果数组；第二遍从右到左用滚动的「右侧乘积」就地乘以已有结果，最终得到除自身以外所有元素的乘积，时间 `O(n)`、额外空间 `O(1)`。

```javascript
/**
 * @param {number[]} nums
 * @return {number[]}
 */
const productExceptSelf = (nums) => {
  const n = nums.length;
  // answer[i] 最终存放「除 nums[i] 外所有元素的乘积」
  const answer = new Array(n).fill(1);

  // 第一遍：从左到右，answer[i] 先记成「i 左侧所有元素的乘积」
  let left = 1;
  for (let i = 0; i < n; i++) {
    answer[i] = left;     // i 左侧乘积（i=0 时左侧为空，记为 1）
    left *= nums[i];      // 滚动累积，供下一个位置使用
  }

  // 第二遍：从右到左，把「i 右侧所有元素的乘积」就地乘上
  let right = 1;
  for (let i = n - 1; i >= 0; i--) {
    answer[i] *= right;   // 左侧乘积 × 右侧乘积
    right *= nums[i];     // 滚动累积右侧乘积
  }

  // 归一化：JS 中 0 与 -0 数学等价，但打印会显示 -0；统一成 0 让输出更直观
  return answer.map((v) => (v === 0 ? 0 : v));
}

// 验证
console.log(productExceptSelf([1, 2, 3, 4]));   // [24, 12, 8, 6]
console.log(productExceptSelf([-1, 1, 0, -3, 3])); // [0, 0, 9, 0, 0]
console.log(productExceptSelf([2, 3, 4, 5]));   // [60, 40, 30, 24]
```

- **时间复杂度：** O(n)，两遍扫描各 `n` 次操作。
- **空间复杂度：** O(1) 额外空间（仅用 `left`、`right` 两个变量；结果数组 `answer` 是题目要求返回的输出，不计入）。
