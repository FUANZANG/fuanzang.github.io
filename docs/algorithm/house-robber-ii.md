# 打家劫舍 II（House Robber II）

**难度：** Medium

## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金。影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

与「打家劫舍」不同的是：**所有房屋都围成一圈**，也就是说第一间房屋和最后一间房屋是相邻的。

给定一个非负整数数组 `nums`，代表每间房屋存放的金额，计算你**在不触动警报装置的情况下**，一夜之内能够偷窃到的最高金额。

### 约束条件

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 1000`

## 示例

**示例 1：**

```javascript
输入: nums = [2, 3, 2]
输出: 3
解释: 你不能先偷窃 1 号房屋（金额 = 2），再偷窃 3 号房屋（金额 = 2），因为它们在同一圈里相邻。
```

**示例 2：**

```javascript
输入: nums = [1, 2, 3, 1]
输出: 4
解释: 先偷窃 1 号房屋（金额 = 1），再偷窃 3 号房屋（金额 = 3），最高金额 = 1 + 3 = 4。
```

**示例 3：**

```javascript
输入: nums = [1, 2, 3]
输出: 3
解释: 偷窃 2 号房屋（金额 = 3）即可，1 号与 3 号相邻不能同时偷。
```

## 提示 / 解题思路

核心障碍在于「首尾相邻」这个环形条件，它让原本简单的线性 DP 无法直接套用到整个数组。

破局点：**把环形拆成两条互斥的线性链**。

既然第 1 间和第 `n` 间不能同时偷，那么任意一种合法方案必然落在以下两种情况之一：

1. **不偷最后一间**：问题退化为在 `nums[0 .. n-2]` 上做线性「打家劫舍」；
2. **不偷第一间**：问题退化为在 `nums[1 .. n-1]` 上做线性「打家劫舍」。

两种情况互不重叠（前者必不含最后一间，后者必不含第一间），且已覆盖全部合法方案，因此答案就是两者的较大值。

线性部分的转移方程：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，即「不偷第 i 间」与「偷第 i 间」取较大值。由于只依赖前两项，用两个滚动变量即可把空间压到 O(1)。

边界：`nums.length === 1` 时只有一个元素，直接返回它（此时区间 `0..n-2` 为空）。

## 解法

把环形拆成「不偷最后一间」和「不偷第一间」两条线性链，各自跑一遍滚动变量的打家劫舍，取较大值。

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
const rob = (nums) => {
  const n = nums.length;
  if (n === 1) return nums[0];

  // 线性打家劫舍：求闭区间 [start, end] 上的最大金额
  const robLinear = (start, end) => {
    let prev2 = 0; // dp[i-2]
    let prev1 = 0; // dp[i-1]
    for (let i = start; i <= end; i++) {
      const cur = Math.max(prev1, prev2 + nums[i]); // 不偷 i 间 vs 偷 i 间
      prev2 = prev1;
      prev1 = cur;
    }
    return prev1;
  };

  // 首尾相邻 => 二选一：不偷最后一间 / 不偷第一间
  return Math.max(robLinear(0, n - 2), robLinear(1, n - 1));
};

// 验证
console.log(rob([2, 3, 2])); // 3
console.log(rob([1, 2, 3, 1])); // 4
console.log(rob([1, 2, 3])); // 3
console.log(rob([7])); // 7
```

- **时间复杂度：** O(n)，两次线性扫描，每次遍历约 n 个元素。
- **空间复杂度：** O(1)，只用了常数个滚动变量。
