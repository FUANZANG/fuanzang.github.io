# 解码方法（Decode Ways）

**难度：** Medium

## 题目描述

你拦截了一条由数字组成的密文，解码规则如下：

```
'1'  -> 'A'
'2'  -> 'B'
...
'25' -> 'Y'
'26' -> 'Z'
```

即一个字符（'1'~'9'）或两个字符（'10'~'26'）可以映射成一个大写字母。同一个数字串可能对应多种解码方式，例如 `"11106"`：

- `(1, 1, 10, 6)` -> `"AAJF"`
- `(11, 10, 6)`   -> `"KJF"`
- `(1, 11, 06)`   -> 非法，因为 `"06"` 不是一个合法的编码（只有 `"6"` 合法）

给定只包含数字的字符串 `s`，返回其所有可能的解码方式数量。如果整个字符串无法被合法解码，返回 `0`。

### 约束条件

- `1 <= s.length <= 100`
- `s` 只包含数字字符，且可能包含前导零（`'0'`）

## 示例

**示例 1：**

```text
输入： s = "12"
输出： 2
解释： "12" 可以解码为 "AB"（1 2）或 "L"（12），共 2 种。
```

**示例 2：**

```text
输入： s = "226"
输出： 3
解释： "226" 可解码为 "BZ"（2 26）、"VF"（22 6）或 "BBF"（2 2 6），共 3 种。
```

**示例 3：**

```text
输入： s = "06"
输出： 0
解释： "06" 不能映射到 "F"，因为存在前导零（"6" 与 "06" 不相等），该编码整体非法，返回 0。
```

## 提示 / 解题思路

这是一个典型的 **动态规划** 问题，关键点是「当前位置的解码方式数，只依赖前两个位置」。

设 `dp[i]` 表示字符串 `s` 的**前 `i` 个字符**（即 `s[0..i-1]`）的解码方式总数。

- **基础情况：** `dp[0] = 1` —— 空串有 1 种「什么都不做」的解码方式，作为递推的垫基（类似爬楼梯的 `dp[0]=1`）。
- **单字符转移：** 若 `s[i-1] !== '0'`，则它可单独解码为一个字母，方式数累加上 `dp[i-1]`。
- **双字符转移：** 若 `i >= 2`，且末两位 `s[i-2..i-1]` 组成的数字在 `[10, 26]` 之间，则这两位可一起解码，方式数累加上 `dp[i-2]`。

> 注意边界：`'0'` 不能单独解码，但可以和前一位组成 `10` 或 `20`。`s.slice(i-2, i)` 对于 `"06"` 会得到数字 `6`（前导零被 Number 吞掉），不在 `[10,26]`，因此不会误加。

空间上可以只用两个变量滚动更新做到 O(1)，下方给出更易读的 O(n) 数组版本，并在文末说明优化点。

## 解法

用一维 DP，`dp[i]` 累加「单字符合法」与「双字符合法」两种情况；遇到前导零天然被两路转移都排除，最终 `dp[n]` 即为答案。

```javascript
/**
 * @param {string} s
 * @return {number}
 */
const numDecodings = (s) => {
  const n = s.length;
  // dp[i] 表示 s 前 i 个字符（s[0..i-1]）的解码方式数
  const dp = new Array(n + 1).fill(0);
  dp[0] = 1; // 空串：1 种「不做任何解码」的基准情况

  for (let i = 1; i <= n; i++) {
    // 情况一：当前字符单独成码（不能是 '0'）
    if (s[i - 1] !== '0') {
      dp[i] += dp[i - 1];
    }
    // 情况二：与上一字符合并成 10~26 的两位编码
    if (i >= 2) {
      const two = Number(s.slice(i - 2, i));
      if (two >= 10 && two <= 26) {
        dp[i] += dp[i - 2];
      }
    }
  }

  return dp[n];
}

// 验证
console.log(numDecodings("12"));  // 2
console.log(numDecodings("226")); // 3
console.log(numDecodings("06"));  // 0
```

- **时间复杂度：** O(n)，遍历一次字符串，每次只做常数级判断。
- **空间复杂度：** O(n)，`dp` 数组长度为 n + 1。若只保留 `dp[i-1]` 与 `dp[i-2]` 两个变量滚动更新，可优化至 O(1)。

## 补充

- **进阶（空间优化）：** 用两个变量 `prev2`（对应 `dp[i-2]`）、`prev1`（对应 `dp[i-1]`）滚动递推，可将空间降到 O(1)。
- **进阶变体：** 若字母映射范围变化（如 `1`~`9` 对应 `'A'`~`'I'`，`10`~`19` 对应 `'J'`~`'S'`，`20`~`26` 对应 `'T'`~`'Z'`，即每位数字最多 3 种含义），思路完全一致，只是双字符判断区间与单字符分支需要相应调整。
- **相关题目：** 本题与「70. 爬楼梯（Climbing Stairs）」的「走到第 i 步可由前一步或前两步转移」结构高度相似，可对照理解 DP 的「状态只依赖有限个前驱」这一核心思想。
