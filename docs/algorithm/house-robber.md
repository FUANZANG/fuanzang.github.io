# 打家劫舍（House Robber）

**难度：** Medium

## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金。影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

给定一个非负整数数组 `nums`，代表每间房屋存放的金额，计算你**在不触动警报装置的情况下**，一夜之内能够偷窃到的最高金额。

### 约束条件

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

## 示例

**示例 1：**

```javascript
输入: nums = [1, 2, 3, 1]
输出: 4
解释: 偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3），最高金额 = 1 + 3 = 4。
```

**示例 2：**

```javascript
输入: nums = [2, 7, 9, 3, 1]
输出: 12
解释: 偷窃 1 号房屋（金额 = 2），偷窃 3 号房屋（金额 = 9），偷窃 5 号房屋（金额 = 1），最高金额 = 2 + 9 + 1 = 12。
```

## 提示 / 解题思路

对于第 `i` 间房屋，只有两种选择：

1. **偷第 `i` 间**：则不能偷第 `i-1` 间，总金额为 `dp[i-2] + nums[i]`。
2. **不偷第 `i` 间**：则总金额等于偷到第 `i-1` 间的最大值，即 `dp[i-1]`。

状态转移方程：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

由于 `dp[i]` 仅依赖于前两个状态，可用滚动变量将空间优化至 O(1)。

## 解法

经典动态规划，用两个变量滚动记录前两间房屋的最大值。

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
const rob = (nums) => {
  if (nums.length === 0) return 0;
  let prev2 = 0; // dp[i-2]
  let prev1 = 0; // dp[i-1]

  for (let i = 0; i < nums.length; i++) {
    const current = Math.max(prev1, prev2 + nums[i]);
    prev2 = prev1;
    prev1 = current;
  }

  return prev1;
};

// 验证
console.log(rob([1, 2, 3, 1])); // 4
console.log(rob([2, 7, 9, 3, 1])); // 12
```

- **时间复杂度：** O(n)，其中 n 为房屋数量
- **空间复杂度：** O(1)，仅使用常数级额外空间
