# 旋转图像（Rotate Image）

**难度：** Medium

## 题目描述

给定一个 n × n 的二维矩阵 `matrix`，请将其顺时针旋转 90 度。

你必须**原地**旋转矩阵，也就是直接修改输入的二维矩阵。不要额外分配另一个 n × n 的二维矩阵来完成旋转。

### 约束条件

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 示例

**示例 1：**

```text
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
解释：
原矩阵：
1 2 3
4 5 6
7 8 9
顺时针旋转 90° 后：
7 4 1
8 5 2
9 6 3
```

**示例 2：**

```text
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

## 提示 / 解题思路

最直观的方法是借助「转置 + 翻转」两个原地操作完成：

1. **转置（transpose）**：沿主对角线（左上—右下）交换 `matrix[i][j]` 与 `matrix[j][i]`，把矩阵变成「行变列」的形式。注意只遍历 `i < j` 的半区，避免一对元素被交换两次。
2. **翻转每一行**：对转置后的每一行做一次 `reverse()`，即可得到顺时针旋转 90° 的结果。

为什么这样可行？以 3×3 为例，先转置得到：

```text
1 4 7
2 5 8
3 6 9
```

再翻转每一行，第一行的 `[1,4,7]` 变成 `[7,4,1]`，恰好是目标矩阵的第一行。规律可推广到任意 n。

另一种等价思路是「按圈旋转」：从最外层到最内层，每次把四条边上的元素按顺时针依次搬到目标位置。转置 + 翻转的方法代码更短、更易验证，本文采用它。

## 解法

思路：先沿主对角线做原地转置，再对每一行原地翻转，两步即可把矩阵顺时针旋转 90°，全程只用到 O(1) 的临时变量。

```javascript
/**
 * 原地顺时针旋转 n×n 矩阵 90°
 * @param {number[][]} matrix
 * @return {void} 直接修改 matrix，无需返回
 */
const rotate = (matrix) => {
  const n = matrix.length;
  // 1. 沿主对角线转置
  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      const tmp = matrix[i][j];
      matrix[i][j] = matrix[j][i];
      matrix[j][i] = tmp;
    }
  }
  // 2. 逐行翻转
  for (let i = 0; i < n; i++) {
    matrix[i].reverse();
  }
  return matrix;
}

// 验证示例 1
console.log(rotate([[1, 2, 3], [4, 5, 6], [7, 8, 9]]));
// 期望输出: [[7,4,1],[8,5,2],[9,6,3]]

// 验证示例 2
console.log(rotate([[5, 1, 9, 11], [2, 4, 8, 10], [13, 3, 6, 7], [15, 14, 12, 16]]));
// 期望输出: [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

- **时间复杂度：** O(n²) — 转置遍历上三角 n(n−1)/2 个元素，逐行翻转共 n²/2 次交换，合计与元素总数成正比。
- **空间复杂度：** O(1) — 仅使用常数个临时变量，原地修改。
