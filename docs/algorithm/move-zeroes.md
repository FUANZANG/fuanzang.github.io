# 移动零（Move Zeroes）

**难度：** Easy

## 题目描述

给定一个整数数组 `nums`，要求**原地**（in-place）把所有的 `0` 都移动到数组的**末尾**，并保持**非零元素的相对顺序**不变。

> 注意：「原地」意味着你不能拷贝另一份数组，所有的修改必须作用在输入数组上；而「相对顺序」意味着 `0` 之间、非零元素之间的顺序关系都不能打乱。

## 示例

**示例 1：**

```
输入：nums = [0,1,2,0,3,0,4]
输出：[1,2,3,4,0,0,0]
解释：原有非零元素的相对顺序 1,2,3,4 被保留，所有 0 被挪到末尾。
```

**示例 2：**

```
输入：nums = [0]
输出：[0]
解释：只有一个元素且为 0，结果与原数组相同。
```

## 提示 / 解题思路

- `1 <= nums.length <= 10^4`
- `nums` 中的元素范围为任意 32 位整数。
- 请尝试使用**常数额外空间**完成本题。

> ⚠️ **请不要直接翻看答案代码**，先尝试自己思考哟～

1. **朴素想法**：先收集所有非零元素到一个临时数组，然后把它们写回原数组，再在末尾补 `0`。正确但**违反了空间复杂度 O(1)** 要求，同时也做了多余的写操作。

2. **双指针 —「移除元素的那种感觉」**：
   - 用一个指针 `k` 指向「下一个非零元素应该放置的位置」。
   - 遍历数组时，遇见**非零**元素就把它交换 / 写到 `nums[k]`，然后 `k++`。
   - 遍历完之后，从 `k` 一直到 `n-1` 全部填上 `0`。

3. **优化写操作** — 思考「最小总写次数」：
   - 交换法会带来额外一次「写 0 到原位」的操作。
   - 如果改成「直接赋值，再最后补齐 0」（而非每次交换），**总写次数**会更少。
   - 何时写 `0` 呢？仅当「赋值发生在 `k !== i`」时才需要补 `0`，这样就可以省掉很多没必要的自赋值。

4. **不要忘记边界**：数组全是 `0`、数组中没有 `0`、只有一个元素。

## 解法

用双指针 `k` 记录「下一个非零元素应该放置的位置」，遍历数组时遇到非零元素就前移到 `nums[k]` 并 `k++`，遍历结束后 `[k, n-1]` 全部填 0；改进写法仅在 `i !== k` 时才交换并回填 0，减少不必要的自赋值写操作，全程原地完成。

```javascript
/**
 * @param {number[]} nums
 * @return {void} 原地修改 nums
 */
const moveZeroes = (nums) => {
  let k = 0
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] !== 0) {
      if (i !== k) {
        nums[k] = nums[i]
        nums[i] = 0
      }
      k++
    }
  }
}

// 验证
const a1 = [0, 1, 2, 0, 3, 0, 4]
moveZeroes(a1)
console.log(a1) // [1,2,3,4,0,0,0]
const a2 = [0]
moveZeroes(a2)
console.log(a2) // [0]
```

- **时间复杂度：** O(n) — 单次遍历数组。
- **空间复杂度：** O(1) — 原地修改，仅用常数额外空间。
