# 子集（Subsets）

**难度：** Medium

## 题目描述

给你一个整数数组 `nums`，数组中的元素**互不相同**。返回该数组所有可能的子集（幂集）。

解集**不能包含重复的子集**。你可以按**任意顺序**返回解集。

### 约束条件

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有元素互不相同

## 示例

### 示例 1

```
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

### 示例 2

```
输入：nums = [0]
输出：[[],[0]]
```

## 提示 / 解题思路

经典的回溯 / DFS 问题。每个元素都有「选」或「不选」两种决策，遍历所有决策路径即可得到全部子集。

**思路分析：**

- 维护一个当前路径 `path`，从空数组 `[]` 开始。
- 每次递归时，先将当前 `path` 的副本加入结果集（保证空集和中间状态都被收录）。
- 然后遍历从当前起始位置开始的每个元素，将其加入 `path`，递归下一层，再回溯弹出。
- 由于元素互不相同，天然无需去重。

**另一种思路（迭代枚举）：** 从空集开始，每次将新元素与已有子集组合生成新子集。时间复杂度相同，但更直观。

## 解法

回溯法：每个元素选或不选，DFS 遍历所有路径，沿途收集子集。

```javascript
/**
 * @param {number[]} nums
 * @return {number[][]}
 */
const subsets = (nums) => {
  const result = [];
  const path = [];

  const backtrack = (start) => {
    result.push([...path]);
    for (let i = start; i < nums.length; i++) {
      path.push(nums[i]);
      backtrack(i + 1);
      path.pop();
    }
  };

  backtrack(0);
  return result;
};

// 验证
console.log(subsets([1, 2, 3]));
// 输出: [[],[1],[1,2],[1,2,3],[1,3],[2],[2,3],[3]]

console.log(subsets([0]));
// 输出: [[],[0]]
```

- **时间复杂度：** O(n × 2ⁿ)，共 2ⁿ 个子集，每个子集复制需要 O(n)
- **空间复杂度：** O(n)，递归栈深度 + 当前路径

## 补充

- 若数组可能含重复元素并要求去重，见 [78. 子集 II](https://leetcode.cn/problems/subsets-ii/)（先排序 + 跳过同层重复元素）。
- 位运算枚举法：用 0 到 2ⁿ - 1 的二进制位表示每个元素是否选中，代码更简洁但本质相同。
