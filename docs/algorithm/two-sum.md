# 两数之和（Two Sum）

**难度：** Easy

## 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** `target` 的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回这两个下标。

### 约束条件

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- 只会存在一个有效答案

## 示例

**示例 1：**

```text
输入：nums = [2, 7, 11, 15], target = 9
输出：[0, 1]
解释：因为 nums[0] + nums[1] == 9，返回 [0, 1]。
```

**示例 2：**

```text
输入：nums = [3, 2, 4], target = 6
输出：[1, 2]
解释：因为 nums[1] + nums[2] == 6，返回 [1, 2]。
```

**示例 3：**

```text
输入：nums = [3, 3], target = 6
输出：[0, 1]
```

## 提示 / 解题思路

最朴素的思路是用双重循环枚举每一对 `(i, j)`，检查 `nums[i] + nums[j] === target`，时间复杂度 O(n²)。在数组规模达到 10^4 时这会超时，需要更优的做法。

核心思想：**用哈希表把「遍历过的数值」与其「下标」记录下来**，这样在遍历到第 `i` 个元素时，只需在 O(1) 时间内查表，看「补数」`target - nums[i]` 是否之前出现过即可——如果出现过，它的下标 `j` 与当前 `i` 就是答案。

要点分析：

- 边遍历、边存表，只需一次线性扫描，时间复杂度降到 O(n)。
- 额外引入一个哈希表，空间复杂度 O(n)。
- 因为只要求返回下标、且保证有唯一解，遇到互补对即可立即返回，无需继续。
- 注意：存的是 `值 -> 下标` 的映射；查表时用「补数」而不是当前值，避免同一个元素被使用两次（例如 `[3, 3]` 的情况，`i=1` 时补数 3 在 `j=0` 已记录，返回 `[0, 1]`）。

## 解法

一句话思路：一次遍历，用 `Map` 记录已访问的数值与下标，对每个元素查其补数是否已存在，存在即返回这对下标。

```javascript
/**
 * @param {number[]} nums
 * @param {number} target
 * @return {number[]}
 */
const twoSum = (nums, target) => {
  const seen = new Map();
  for (let i = 0; i < nums.length; i++) {
    const complement = target - nums[i];
    if (seen.has(complement)) {
      return [seen.get(complement), i];
    }
    seen.set(nums[i], i);
  }
  return []; // 题目保证有解，正常流程不会执行到这里
}

// 验证
console.log(twoSum([2, 7, 11, 15], 9)); // [0, 1]
console.log(twoSum([3, 2, 4], 6)); // [1, 2]
console.log(twoSum([3, 3], 6)); // [0, 1]
```

- **时间复杂度：** O(n)（只遍历数组一次，每次 Map 操作均为 O(1) 均摊）
- **空间复杂度：** O(n)（最坏情况下哈希表存储全部 n 个元素）
