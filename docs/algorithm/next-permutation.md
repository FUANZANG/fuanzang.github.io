# 下一个排列（Next Permutation）

**难度：** Medium

## 题目描述

实现一个算法，将给定数字列表的排列替换为字典序下一个更大的排列。如果不存在下一个更大的排列（即当前排列是降序排列），则将数字重新排列为最小的排列（即升序排列）。

**必须原地修改**，只允许使用额外常数空间。

### 约束条件

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 100`

## 示例

### 示例 1

```
输入: nums = [1,2,3]
输出: [1,3,2]
解释: 下一个排列是 [1,3,2]。
```

### 示例 2

```
输入: nums = [3,2,1]
输出: [1,2,3]
解释: [3,2,1] 不存在下一个更大的排列，因此将其重排为最小的排列 [1,2,3]。
```

### 示例 3

```
输入: nums = [1,1,5]
输出: [1,5,1]
```

## 提示 / 解题思路

1. **找「拐点」**：从右往左找到第一个满足 `nums[i] < nums[i+1]` 的位置 `i`。这个位置就是需要调整的"拐点"——它右侧部分是降序（即局部最大），所以需要把 `nums[i]` 换成一个更大的值。

2. **找替换目标**：在 `i` 右侧（降序部分）从右往左找到第一个大于 `nums[i]` 的元素 `nums[j]`，交换它们。

3. **反转后缀**：交换后，`i` 右侧仍然是降序的，将其反转为升序即可得到最小的"下一个"排列。

4. **特殊情况**：如果整个数组是降序排列（没有找到拐点），直接将整个数组反转即可。

**关键点**：为什么从右往左找第一个大于 `nums[i]` 的元素交换后，反转后缀就得到字典序最小？因为交换后后缀仍然保持降序，反转就是升序，升序就是该后缀能组成的最小排列。

## 解法

双指针 + 原地反转，一次扫描找拐点，一次扫描找替换点，一次反转后缀。

```javascript
/**
 * @param {number[]} nums
 * @return {void} 原地修改，不返回值
 */
const nextPermutation = (nums) => {
  const n = nums.length;
  // 步骤1：从右往左找拐点 i
  let i = n - 2;
  while (i >= 0 && nums[i] >= nums[i + 1]) {
    i--;
  }
  if (i >= 0) {
    // 步骤2：从右往左找第一个大于 nums[i] 的元素
    let j = n - 1;
    while (nums[j] <= nums[i]) {
      j--;
    }
    // 交换 nums[i] 和 nums[j]
    [nums[i], nums[j]] = [nums[j], nums[i]];
  }
  // 步骤3：反转 i 之后的后缀
  let left = i + 1;
  let right = n - 1;
  while (left < right) {
    [nums[left], nums[right]] = [nums[right], nums[left]];
    left++;
    right--;
  }
};

// 验证
const test1 = [1, 2, 3];
nextPermutation(test1);
console.log(test1); // [1, 3, 2]

const test2 = [3, 2, 1];
nextPermutation(test2);
console.log(test2); // [1, 2, 3]

const test3 = [1, 1, 5];
nextPermutation(test3);
console.log(test3); // [1, 5, 1]
```

- **时间复杂度：** O(n)，其中 n 为数组长度。最坏情况下三次线性扫描（找拐点、找替换点、反转后缀）。
- **空间复杂度：** O(1)，原地修改，只使用了常数个额外变量。

## 补充

该算法是经典的"下一个排列"问题，也是 C++ STL 中 `std::next_permutation` 的标准实现思路。其核心在于利用了**字典序排列的相邻关系**：相邻两个排列之间仅通过一次最小幅度的交换+反转得到。
