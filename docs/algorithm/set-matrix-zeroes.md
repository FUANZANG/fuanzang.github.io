# 矩阵置零

**难度：** Medium

## 题目描述

给定一个 `m x n` 的矩阵，如果一个元素是 `0`，则将其所在的**整行**和**整列**的元素都置为 `0`。

请你**原地**完成操作，即直接在原矩阵上修改，不要返回新矩阵。

## 示例

**示例 1：**

输入：
```
[
  [1, 1, 1],
  [1, 0, 1],
  [1, 1, 1]
]
```

输出：
```
[
  [1, 0, 1],
  [0, 0, 0],
  [1, 0, 1]
]
```

**示例 2：**

输入：
```
[
  [0, 1, 2, 0],
  [3, 4, 5, 2],
  [1, 3, 1, 5]
]
```

输出：
```
[
  [0, 0, 0, 0],
  [0, 4, 5, 0],
  [0, 3, 1, 0]
]
```

## 提示 / 解题思路

> 以下提示由浅入深，你可以选择性阅读，尽量不要一次性看完全部提示。

1. **第一步 — 暴力法（理解题意即可）**
   - 遍历整个矩阵，记录所有值为 `0` 的元素坐标。
   - 再次遍历这些坐标，将对应行和列全部置零。
   - 这种方法需要 O(m × n) 的额外空间来存储零的位置。

2. **第二步 — 优化空间到 O(m + n)**
   - 用两个布尔数组（或集合）分别记录「哪些行需要置零」和「哪些列需要置零」。
   - 第一次遍历：标记包含 `0` 的行和列。
   - 第二次遍历：根据标记数组将对应行、列置零。
   - 空间复杂度从 O(mn) 降到了 O(m + n)。

3. **第三步（进阶）— 用 O(1) 额外空间**
   - 核心想法：**利用矩阵的第一行和第一列作为标记数组**。
   - 但第一行和第一列本身也可能需要被置零，所以需要用两个额外的变量分别记录「第一行」和「第一列」是否原本就包含 `0`。
   - 遍历顺序很重要：
     - **第一步**：用两个变量记住第一行和第一列的状态。
     - **第二步**：遍历除第一行和第一列之外的区域（即从第 1 行第 1 列开始），如果 `matrix[i][j] == 0`，则将 `matrix[i][0]` 和 `matrix[0][j]` 设为 `0` 作为标记。
     - **第三步**：再次遍历除第一行和第一列之外的区域，如果对应的行标记或列标记为 `0`，则将当前元素置 `0`。
     - **第四步**：最后根据之前保存的两个变量，决定是否将第一行和第一列整体置零。

4. **边界情况思考**
   - 矩阵只有一行或一列的情况。
   - 矩阵中全是 `0` 或全不是 `0` 的情况。
   - 第一行或第一列本身就包含 `0` 的情况。

## 解法

原地 O(1) 额外空间：借用矩阵的第一行和第一列作为标记数组。先用两个布尔变量 `firstRowZero / firstColZero` 记录首行首列自身是否含 0；再扫描内部区域，若 `matrix[i][j] === 0` 则将 `matrix[i][0]` 与 `matrix[0][j]` 置 0 作为标记；最后根据标记把内部清零，并依据两个布尔变量决定是否清零首行首列。先处理内部再处理边界，避免标记被覆盖。

```javascript
/**
 * @param {number[][]} matrix
 * @return {void} 原地修改，不返回新矩阵
 */
const setZeroes = (matrix) => {
  const m = matrix.length,
    n = matrix[0].length
  let firstRowZero = false,
    firstColZero = false
  for (let i = 0; i < m; i++) if (matrix[i][0] === 0) firstColZero = true
  for (let j = 0; j < n; j++) if (matrix[0][j] === 0) firstRowZero = true
  for (let i = 1; i < m; i++)
    for (let j = 1; j < n; j++)
      if (matrix[i][j] === 0) {
        matrix[i][0] = 0
        matrix[0][j] = 0
      }
  for (let i = 1; i < m; i++)
    for (let j = 1; j < n; j++)
      if (matrix[i][0] === 0 || matrix[0][j] === 0) matrix[i][j] = 0
  if (firstRowZero) for (let j = 0; j < n; j++) matrix[0][j] = 0
  if (firstColZero) for (let i = 0; i < m; i++) matrix[i][0] = 0
}

// 验证
let m1 = [
  [1, 1, 1],
  [1, 0, 1],
  [1, 1, 1],
]
setZeroes(m1)
console.log(JSON.stringify(m1)) // [[1,0,1],[0,0,0],[1,0,1]]
let m2 = [
  [0, 1, 2, 0],
  [3, 4, 5, 2],
  [1, 3, 1, 5],
]
setZeroes(m2)
console.log(JSON.stringify(m2)) // [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

- **时间复杂度：** O(m × n)，两次扫描矩阵。
- **空间复杂度：** O(1)，仅用两个布尔变量（不计矩阵自身）。
