# 每日温度

**难度：** Medium

## 题目描述

给定一个整数数组 `temperatures`，其中 `temperatures[i]` 表示第 `i` 天的气温。

请返回一个数组 `result`，其中 `result[i]` 表示在第 `i` 天之后，需要**等待多少天**才能等到一个**更高**的温度。如果之后都没有更高的温度，对应的结果用 `0` 表示。

**约束条件**：
- `1 <= temperatures.length <= 10^5`
- `1 <= temperatures[i] <= 100`
- 期望时间复杂度为 `O(n)`，空间复杂度为 `O(n)`

## 示例

**输入**: `temperatures = [73, 74, 75, 71, 69, 72, 76, 71]`

**输出**: `[1, 1, 4, 2, 1, 1, 0, 0]`

**解释**:
- 第 0 天 (73°)：下一天就升温到 74°，等待 1 天。
- 第 1 天 (74°)：下一天就升温到 75°，等待 1 天。
- 第 2 天 (75°)：要等到第 6 天 (76°) 才有更高温度，等待 4 天。
- 第 3 天 (71°)：要等到第 5 天 (72°) 才有更高温度，等待 2 天。
- 第 4 天 (69°)：要等到第 5 天 (72°) 才有更高温度，等待 1 天。
- 第 5 天 (72°)：要等到第 6 天 (76°) 才有更高温度，等待 1 天。
- 第 6 天 (76°)：后面没有更高温度，等待 0 天。
- 第 7 天 (71°)：后面没有更高温度，等待 0 天。

**输入**: `temperatures = [30, 40, 50, 60]`

**输出**: `[1, 1, 1, 0]`

**解释**: 每一天之后的第一天温度都更高，直到最后一天。

**输入**: `temperatures = [80, 70, 60, 50]`

**输出**: `[0, 0, 0, 0]`

**解释**: 每一天之后的温度都更低，因此没有任何一天能等到更高的温度。

## 提示 / 解题思路

双重循环，对每一天向右扫描找到第一个更高的温度。时间复杂度为 `O(n^2)`，在数据量达到 `10^5` 时会超时。

这是解决「下一个更大元素」系列问题的经典技巧：

1. **栈中存储什么**：存储**温度的下标**（而不是温度值本身），这样既能获取下标间的距离，又能通过下标获取温度值。

2. **栈的性质**：维护一个**单调递减**的栈。从栈顶到栈底，温度值递减。这样，对于任意一个新元素，栈顶就是它「最近右边比它高的元素」的候选。

3. **遍历过程**：从左到右遍历每一天的温度：
   - 当当前温度 `T[i]` 大于栈顶下标对应的温度 `T[stack.top]` 时，说明找到了「栈顶那个下标」的下一个更高温度 → **弹出**栈顶，计算距离 `(i - stack.top)`，写入结果。
   - **重复**这个弹出操作，直到栈为空或栈顶温度 ≥ 当前温度。
   - 将当前下标 `i` 压入栈。

4. **为什么是 `O(n)`**：每个下标最多被压入栈一次、弹出栈一次，因此总操作次数不超过 `2n`，均摊复杂度为 `O(n)`。

## 解法

单调栈求「下一个更大元素」：栈内存下标，维持单调递减；遇到更高温度就弹出并计算等待天数。

```javascript
/**
 * @param {number[]} temperatures
 * @return {number[]}
 */
const dailyTemperatures = (temperatures) => {
  const n = temperatures.length
  const res = new Array(n).fill(0)
  const stack = [] // 存下标，栈顶温度最低

  for (let i = 0; i < n; i++) {
    // 当前温度比栈顶对应温度高 → 栈顶找到了「下一个更高温」
    while (
      stack.length &&
      temperatures[i] > temperatures[stack[stack.length - 1]]
    ) {
      const idx = stack.pop()
      res[idx] = i - idx // 等待天数 = 距离
    }
    stack.push(i)
  }
  // 栈中剩余元素后面没有更高温 → res 保持 0（已初始化）
  return res
}

// 验证
console.log(dailyTemperatures([73, 74, 75, 71, 69, 72, 76, 71]))
// [1, 1, 4, 2, 1, 1, 0, 0]
console.log(dailyTemperatures([30, 40, 50, 60])) // [1, 1, 1, 0]
console.log(dailyTemperatures([80, 70, 60, 50])) // [0, 0, 0, 0]
```

- **时间复杂度：** O(n)，每个下标最多入栈一次、出栈一次
- **空间复杂度：** O(n)，栈和结果数组

#### 关键观察

对于第 `i` 天，我们需要找到**右侧第一个比它更高的温度**所在的天数。这个本质上是一个**「Next Greater Element」** (NGE) 问题。

#### 进一步思考

- 如果需要找「下一个更小的元素」，栈的递减/递增顺序会如何变化？
- 如果温度范围较大（例如 `10^9`），这种方法仍然适用吗？
- 栈在最后可能会剩下一些元素，这些元素的结果应该是什么？
