# 合并重叠区间

**难度：** Medium

## 题目描述

给定一个由多个区间组成的数组，每个区间用 `[start, end]` 表示（其中 `start <= end`）。请合并所有**重叠**的区间，返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

**区间重叠的定义**：两个区间 `[a, b]` 和 `[c, d]` 重叠，当且仅当 `c <= b` 且 `a <= d`。换句话说，一个区间的起点小于等于另一个区间的终点，且反之亦然。

**约束条件**：
- `1 <= intervals.length <= 10^4`
- `0 <= start <= end <= 10^5`

## 示例

**输入**：
```javascript
intervals = [
  [1, 3],
  [2, 6],
  [8, 10],
  [15, 18],
]
```

**输出**：
```javascript
;[
  [1, 6],
  [8, 10],
  [15, 18],
]
```

**解释**：区间 `[1, 3]` 和 `[2, 6]` 重叠，合并为 `[1, 6]`。其余区间不重叠，保持不变。

**输入**：
```javascript
intervals = [
  [1, 4],
  [4, 5],
]
```

**输出**：
```javascript
;[[1, 5]]
```

**解释**：区间 `[1, 4]` 和 `[4, 5]` 在端点处相接，也算重叠，合并为 `[1, 5]`。

## 提示 / 解题思路

<details>
<summary>点击查看提示（建议先自己思考）</summary>

1. **排序是关键**：如果区间按 `start` 升序排列，重叠的区间一定会相邻出现。想一想为什么？

2. **贪心策略**：排序后遍历区间数组，维护一个"当前合并区间"。对于每个新区间：
   - 如果它的 `start` <= 当前合并区间的 `end`，说明有重叠 → 更新合并区间的 `end` 为两者的 `max(end)`
   - 否则没有重叠 → 将当前合并区间加入结果集，并把新区间作为新的"当前合并区间"

3. **边界情况**：
   - 输入只有一个区间时直接返回
   - 包含关系（如 `[1, 10]` 和 `[2, 5]`）需要正确处理 `max(end)`
   - 端点相接的情况（如 `[1, 4]` 和 `[4, 5]`）也算重叠

4. **时间复杂度目标**：排序 `O(n log n)` + 遍历 `O(n)` = **O(n log n)**

</details>

## 解法

先将区间按起点升序排序，再贪心遍历：若当前区间与结果中最后一个区间重叠（起点 <= 其终点）则合并，否则直接加入结果。

```javascript
/**
 * @param {number[][]} intervals
 * @return {number[][]}
 */
const merge = (intervals) => {
  intervals.sort((a, b) => a[0] - b[0])
  const res = []
  for (const interval of intervals) {
    if (res.length === 0 || res[res.length - 1][1] < interval[0]) {
      res.push([interval[0], interval[1]])
    } else {
      res[res.length - 1][1] = Math.max(res[res.length - 1][1], interval[1])
    }
  }
  return res
}

// 验证
console.log(
  merge([
    [1, 3],
    [2, 6],
    [8, 10],
    [15, 18],
  ]),
) // [[1,6],[8,10],[15,18]]
console.log(
  merge([
    [1, 4],
    [4, 5],
  ]),
) // [[1,5]]
```

- **时间复杂度：** O(n log n)，排序占主导。
- **空间复杂度：** O(n)，结果数组空间（不计排序栈空间）。
