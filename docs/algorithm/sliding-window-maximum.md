# 滑动窗口最大值（Sliding Window Maximum）

**难度：** Medium

## 题目描述

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字，滑动窗口每次只向右移动一位。

返回滑动窗口中的最大值。

### 约束条件

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

## 示例

**示例 1：**

```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
  滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7      3
 1 [3  -1  -3] 5  3  6  7      3
 1  3 [-1  -3  5] 3  6  7      5
 1  3  -1 [-3  5  3] 6  7      5
 1  3  -1  -3 [5  3  6] 7      6
 1  3  -1  -3  5 [3  6  7]     7
```

**示例 2：**

```
输入：nums = [1], k = 1
输出：[1]
```

## 提示 / 解题思路

暴力解法的时间复杂度为 O(n×k)：对每个窗口遍历求最大值，在数据量大时会超时。

**单调队列（Monotonic Deque）** 是此类「滑动窗口最值」问题的经典解法：

1. 使用双端队列（数组模拟），**队头始终保存当前窗口最大值对应的下标**。
2. 队列中的下标对应的值从队头到队尾**严格递减**（维护单调性）。
3. 入队新元素时，从队尾弹出所有比它小的下标（这些元素不可能成为后续窗口的最大值）。
4. 移动窗口时，如果队头下标已滑出窗口（下标 ≤ i - k），则从队头弹出。
5. 当窗口形成后（i ≥ k - 1），队头对应的值即为当前窗口最大值，加入结果。

关键点：队列存的是**下标**而非值，这样才能判断元素是否已滑出窗口。

## 解法

使用单调递减双端队列维护窗口最大值对应的下标，队头为当前窗口最大值。

```javascript
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number[]}
 */
const maxSlidingWindow = (nums, k) => {
  const deque = []; // 存下标，队头到队尾对应值递减
  const result = [];

  for (let i = 0; i < nums.length; i++) {
    // 1. 移除队头已滑出窗口的元素
    if (deque.length > 0 && deque[0] <= i - k) {
      deque.shift();
    }

    // 2. 从队尾移除所有比当前元素小的下标（维护递减单调性）
    while (deque.length > 0 && nums[deque[deque.length - 1]] < nums[i]) {
      deque.pop();
    }

    // 3. 当前下标入队
    deque.push(i);

    // 4. 窗口形成后，记录最大值（队头对应的值）
    if (i >= k - 1) {
      result.push(nums[deque[0]]);
    }
  }

  return result;
};

// 验证
console.log(maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3)); // [3, 3, 5, 5, 6, 7]
console.log(maxSlidingWindow([1], 1)); // [1]
```

- **时间复杂度：** O(n)，每个元素最多入队和出队各一次
- **空间复杂度：** O(k)，双端队列最多保存 k 个元素
