# 爬楼梯（Climbing Stairs）

**难度：** Easy

## 题目描述

给你一个整数 `n`，表示你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

### 约束条件

- `1 <= n <= 45`

## 示例

**示例 1：**

```text
输入：n = 2
输出：2
解释：有两种方法可以爬到楼顶。
  1. 1 阶 + 1 阶
  2. 2 阶
```

**示例 2：**

```text
输入：n = 3
输出：3
解释：有三种方法可以爬到楼顶。
  1. 1 阶 + 1 阶 + 1 阶
  2. 1 阶 + 2 阶
  3. 2 阶 + 1 阶
```

## 提示 / 解题思路

到达第 `n` 阶楼梯，只能从第 `n-1` 阶跨 1 步上来，或者从第 `n-2` 阶跨 2 步上来。因此：

`f(n) = f(n-1) + f(n-2)`

这正是斐波那契数列的递推关系。边界条件：`f(1) = 1`，`f(2) = 2`。

由于只需要前两个状态即可计算当前值，可以用两个变量滚动更新，将空间复杂度优化到 O(1)。

## 解法

动态规划，用两个变量滚动优化。

```javascript
const climbStairs = (n) => {
  if (n <= 2) return n;
  let a = 1, b = 2;
  for (let i = 3; i <= n; i++) {
    const temp = b;
    b = a + b;
    a = temp;
  }
  return b;
};

// 验证
console.log(climbStairs(2)); // 2
console.log(climbStairs(3)); // 3
console.log(climbStairs(5)); // 8
```

- **时间复杂度：** O(n)
- **空间复杂度：** O(1)

## 补充

- 若将每次可爬的台阶数扩展为 1~k 个，则递推变为 `f(n) = f(n-1) + f(n-2) + ... + f(n-k)`，可用滑动窗口优化。
- 进阶可尝试矩阵快速幂将时间复杂度降至 O(log n)。
