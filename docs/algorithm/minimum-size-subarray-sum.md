# 长度最小的子数组（Minimum Size Subarray Sum）

**难度：** Medium

## 题目描述

给定一个含有 `n` 个**正整数**的数组 `nums` 和一个正整数 `target`。

请你找出数组中**和 ≥ target** 的、**长度最小**的**连续子数组**（子数组是数组中连续的一段元素），并返回其长度。

如果不存在这样的子数组，请返回 `0`。

要求：尽量在 **O(n)** 时间复杂度内完成。

## 示例

**输入：**
```js
nums = [2, 3, 1, 2, 4, 3]
target = 7
```

**输出：**
```js
2
```

**解释：** 子数组 `[4, 3]` 的和为 `7`，长度为 `2`，是满足条件的最短连续子数组。

**输入：**
```js
nums = [1, 4, 4]
target = 4
```

**输出：**
```js
1
```

**解释：** 子数组 `[4]`（第一个或第二个 `4`）的和即为 `4`，长度为 `1`。

**输入：**
```js
nums = [1, 1, 1, 1, 1, 1, 1, 1]
target = 11
```

**输出：**
```js
0
```

**解释：** 所有元素之和只有 `8 < 11`，不存在满足条件的子数组，返回 `0`。

## 提示 / 解题思路

1. **暴力法的代价**：枚举所有左右端点组合，时间复杂度是 O(n²)，在 `n` 较大时会超时。思考有没有只遍历一次的方法。

2. **滑动窗口（双指针）思路**：
   - 维护一个窗口 `[left, right]`（左右指针都从 `0` 开始），用一个变量 `sum` 记录当前窗口内元素的和。
   - 不断把 `right` 向右移动，**扩大**窗口，并把 `nums[right]` 加入 `sum`。
   - 一旦 `sum >= target`，说明当前窗口满足条件。此时记录窗口长度 `right - left + 1`，并尝试把 `left` 向右移动来**收缩**窗口（同时从 `sum` 中减去 `nums[left]`），只要收缩后 `sum` 仍然 `>= target`，就继续收缩——这样能找到以当前 `right` 为结尾的最短合法窗口。
   - 在整个过程中，用一个变量持续记录"见过的最小合法长度"即可。

3. **为什么是 O(n)**：每个元素最多被 `right` 指针访问一次、被 `left` 指针访问一次，两个指针都只向右走，不会回退。

4. **边界情况**：注意题目要求是正整数数组，因此收缩窗口时 `sum` 会严格减小，逻辑才成立；另外要初始化"最小长度"为一个比任何可能答案都大的值（或用一个哨兵标记），最后判断是否真的找到过合法子数组。

5. **进阶思考**：如果数组里允许出现负数或 `0`，滑动窗口的收缩逻辑还成立吗？如果不成立，你会改用什么思路（提示：前缀和 + 单调结构）？

> 自己动手实现后，再回头对照上面的思路检查：是否真的做到了只遍历一次？最小长度在"没找到"时是否正确返回了 `0`？

## 解法

用滑动窗口（双指针）在 O(n) 内求解：维护左指针 `left` 与右指针 `right`，右指针不断右移并把 `nums[right]` 加入窗口和 `sum`；一旦 `sum >= target`，就记录当前窗口长度并尝试右移 `left` 收缩窗口（同时减去 `nums[left]`），始终保持「以当前 right 结尾的最短合法窗口」，全局取最小长度；从未满足条件则返回 0。

```javascript
/**
 * @param {number} target
 * @param {number[]} nums
 * @return {number}
 */
const minSubArrayLen = (target, nums) => {
  let left = 0,
    sum = 0,
    minLen = Infinity
  for (let right = 0; right < nums.length; right++) {
    sum += nums[right]
    while (sum >= target) {
      minLen = Math.min(minLen, right - left + 1)
      sum -= nums[left]
      left++
    }
  }
  return minLen === Infinity ? 0 : minLen
}

// 验证
console.log(minSubArrayLen(7, [2, 3, 1, 2, 4, 3])) // 2
console.log(minSubArrayLen(4, [1, 4, 4])) // 1
console.log(minSubArrayLen(11, [1, 1, 1, 1, 1, 1, 1, 1])) // 0
```

- **时间复杂度：** O(n)（左右指针各最多遍历数组一次）
- **空间复杂度：** O(1)
