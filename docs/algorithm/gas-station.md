# 加油站（Gas Station）

**难度：** Medium

## 题目描述

在一条环路上有 `n` 个加油站。第 `i` 个加油站有 `fuel[i]` 升汽油。

你开车旅行一周所需的总汽油量是正数。从第 `i` 个加油站开车到第 `i + 1` 个加油站需要 `cost[i]` 升汽油（下标取模运算，也就是说，最后一个加油站与第一个加油站之间是相连的）。

你从其中一个加油站出发，开始时油箱为空，且油箱容量无限大。

**返回可以完成一次巡游的起始加油站的下标。** 如果无法完成巡游，则返回 `-1`。

如果存在解，**保证它是唯一的**。

### 约束条件

- `fuel.length == cost.length`
- `n == fuel.length`
- `1 <= n <= 10^5`
- `0 <= fuel[i], cost[i] <= 10^4`

## 示例

**示例 1：**

输入：
```
fuel = [1,2,3,4,5]
cost = [3,4,5,1,2]
```
输出：
```
3
```
解释：
- 从 3 号加油站出发，油量为 4
- 前往 4 号加油站，油量 = 4 - 1 + 5 = 8
- 前往 0 号加油站，油量 = 8 - 2 + 1 = 7
- 前往 1 号加油站，油量 = 7 - 3 + 2 = 6
- 前往 2 号加油站，油量 = 6 - 4 + 3 = 5
- 回到 3 号加油站，油量 = 5 - 5 + 4 = 4，完成巡游
- 注意从其他任意加油站出发都无法完成巡游，所以返回 3

**示例 2：**

输入：
```
fuel = [2,3,4]
cost = [3,4,3]
```
输出：
```
-1
```
解释：
- 从 0 号加油站出发，你最多可以到达 1 号加油站
- 从 1 号加油站出发，你最多可以到达 2 号加油站
- 从 2 号加油站出发，你无法到达 0 号加油站
- 由于无论如何都无法完成整圈巡游，返回 -1

## 提示 / 解题思路

**贪心（一次遍历）**：

**第 1 步：判断无解**。若所有加油站的总油量小于总耗油量（`sum(fuel) < sum(cost)`），则无论从哪里出发都完不成巡游，直接返回 `-1`。

**第 2 步：找起点**。设当前候选起点为 `start`，从 `start` 开始累加净油量 `tank += fuel[i] - cost[i]`。一旦 `tank < 0`，说明**从 `start` 到 `i` 的这一段整体是"亏油"的**，那么答案一定不是 `start..i` 中的任何一个站（从其中任何一站出发，走不到 `i` 时油就先断了，而且补上前面的亏空后更不可能走完全程）。于是把候选起点重置为 `i + 1`，`tank` 清零继续累加。

**第 3 步：收尾**。遍历结束后，若总净油量非负，当前 `start` 就是唯一解；否则返回 `-1`。

要点分析：

- 净油量一旦在某站 `i` 首次变负，"起点必在 `i + 1` 之后"是一个可以严格证明的结论，因此整个贪心只需一趟 O(n) 遍历，不需要二次验证。
- 本题与「跳跃游戏」的贪心思想一脉相承：都在维护"可达范围"，一旦越过边界就前移起点。

## 解法

贪心一次遍历：净油量在 `i` 处变负就把起点重置为 `i+1`，结束时总净油量非负即 `start` 为解，否则 `-1`。

```javascript
/**
 * @param {number[]} fuel
 * @param {number[]} cost
 * @return {number}
 */
const canCompleteCircuit = (fuel, cost) => {
  let total = 0; // 全程净油量
  let tank = 0;  // 从候选起点 start 出发的净油量
  let start = 0;
  for (let i = 0; i < fuel.length; i++) {
    const diff = fuel[i] - cost[i];
    total += diff;
    tank += diff;
    if (tank < 0) {
      tank = 0;
      start = i + 1;
    }
  }
  return total >= 0 ? start : -1;
};

// 验证
console.log(canCompleteCircuit([1, 2, 3, 4, 5], [3, 4, 5, 1, 2])); // 3
console.log(canCompleteCircuit([2, 3, 4], [3, 4, 3])); // -1
```

- **时间复杂度：** O(n)
- **空间复杂度：** O(1)
