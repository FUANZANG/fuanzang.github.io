# 腐烂的橘子（Rotting Oranges）

**难度：** Medium

## 题目描述

在给定的 `m x n` 网格 `grid` 中，每个单元格可以有以下三个值之一：

- `0` 代表空单元格；
- `1` 代表新鲜橘子；
- `2` 代表腐烂的橘子。

每分钟，任何与腐烂橘子相邻（上、下、左、右四个方向）的新鲜橘子都会腐烂。

返回直到单元格中没有新鲜橘子为止所必须经过的**最小分钟数**。如果不可能，返回 `-1`。

### 约束条件

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 10`
- `grid[i][j]` 仅为 `0`、`1` 或 `2`

## 示例

```text
示例 1：
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4
解释：
第 1 分钟：左下角的橘子腐烂；
第 2 分钟：周围更多橘子腐烂；
第 3 分钟：继续向外扩散；
第 4 分钟：最后一批新鲜橘子腐烂。
```

```text
示例 2：
输入：grid = [[2,1,1],[0,1,1],[1,0,1]]
输出：-1
解释：左下角（第 3 行第 1 列）的橘子永远不会腐烂，因为它被空单元格隔开。
```

```text
示例 3：
输入：grid = [[0,2]]
输出：0
解释：网格中没有新鲜橘子，因此无需任何分钟。
```

## 提示 / 解题思路

**要点分析**

1. 腐烂是**同时、逐层**向外扩散的：每一分钟，所有当前腐烂的橘子会一起感染它们四邻的新鲜橘子。这种「同一层同时扩展」的特征正是**广度优先搜索（BFS）**的典型场景。
2. 网格里可能有**多个**初始腐烂橘子，因此这是**多源 BFS**：一开始把所有腐烂橘子的坐标一次性入队，作为第 0 层。
3. 用「层」来计量分钟数：每处理完一整层（即当前队列里同一分钟的橘子），就代表过去了 1 分钟。
4. 需要额外统计**新鲜橘子总数** `fresh`：每腐烂一个就减一。BFS 结束后若 `fresh > 0`，说明有橘子被空单元格隔开、永远无法腐烂，返回 `-1`。
5. 边界情况：若一开始 `fresh === 0`，直接返回 `0`。

**伪代码思路**

```text
收集所有腐烂橘子坐标入队，统计新鲜橘子数 fresh
若 fresh == 0 直接返回 0
while 队列非空：
    size = 当前层的橘子数
    本层是否有扩散 = false
    for 处理本层每一个橘子：
        对四个方向：
            若是新鲜橘子 → 标记腐烂、fresh--、入队、本层扩散 = true
    若本层发生扩散 → 分钟数 +1
返回 fresh == 0 ? 分钟数 : -1
```

## 解法

多源 BFS 逐层扩散：把所有初始腐烂橘子入队，每一层代表一分钟，同时记录剩余新鲜橘子数，最终无剩余则返回层数，否则返回 -1。

```javascript
/**
 * @param {number[][]} grid
 * @return {number}
 */
const orangesRotting = (grid) => {
  const m = grid.length;
  const n = grid[0].length;
  const queue = [];
  let fresh = 0;

  // 收集所有腐烂橘子作为多源 BFS 起点，并统计新鲜橘子数量
  for (let i = 0; i < m; i++) {
    for (let j = 0; j < n; j++) {
      if (grid[i][j] === 2) queue.push([i, j]);
      else if (grid[i][j] === 1) fresh++;
    }
  }

  // 没有新鲜橘子，0 分钟即可
  if (fresh === 0) return 0;

  const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];
  let minutes = 0;
  let head = 0;

  while (head < queue.length) {
    const size = queue.length - head; // 当前这一层（同一分钟）腐烂的橘子数
    let spread = false;

    for (let k = 0; k < size; k++) {
      const [x, y] = queue[head++];
      for (const [dx, dy] of dirs) {
        const nx = x + dx;
        const ny = y + dy;
        if (nx >= 0 && nx < m && ny >= 0 && ny < n && grid[nx][ny] === 1) {
          grid[nx][ny] = 2; // 就地标记为腐烂，天然去重
          fresh--;
          queue.push([nx, ny]);
          spread = true;
        }
      }
    }

    if (spread) minutes++; // 本层发生了扩散，才计入 1 分钟
  }

  return fresh === 0 ? minutes : -1;
};

// 验证
console.log(orangesRotting([[2, 1, 1], [1, 1, 0], [0, 1, 1]])); // 4
console.log(orangesRotting([[2, 1, 1], [0, 1, 1], [1, 0, 1]])); // -1
console.log(orangesRotting([[0, 2]])); // 0
```

- **时间复杂度：** O(m × n)。每个单元格最多入队、出队一次。
- **空间复杂度：** O(m × n)。最坏情况下队列同时容纳整个网格的坐标。

## 补充

- **对比同类题型**：与 [岛屿数量](./number-of-islands.md) 的 DFS 洪泛不同，本题需要「最短扩散时间」，因此必须用 BFS 而非 DFS。
- **变形题「1091. 二进制矩阵中的最短路径」**：同样用 BFS 求最短距离，但为单源且允许八方向移动。
- **优化提示**：由于网格最多 `10 × 10`，坐标可编码为 `x * n + y` 的单个整数入队，减少数组对象开销；也可用「剩余新鲜橘子数」在循环外一次性判定。
