# 只出现一次的数字（Single Number）

**难度：** Easy

## 题目描述

给定一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

### 约束条件

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除了某个元素只出现一次外，其余每个元素均出现两次。

## 示例

**示例 1：**

```text
输入：nums = [2, 2, 1]
输出：1
```

**示例 2：**

```text
输入：nums = [4, 1, 2, 1, 2]
输出：4
```

**示例 3：**

```text
输入：nums = [1]
输出：1
```

## 提示 / 解题思路

- 最直接的想法是用哈希表统计每个数字出现的次数，最后扫描找出计数为 1 的那个。但哈希表会占用 `O(n)` 的额外空间，不满足「常量额外空间」的要求。
- 思考一个满足「出现两次抵消、出现一次保留」的运算。异或（XOR）恰好具备这个性质：
  - 任何数与自身异或结果为 `0`：`a ^ a = 0`
  - 任何数与 `0` 异或结果仍为自身：`a ^ 0 = a`
  - 异或满足交换律与结合律：`a ^ b ^ a = (a ^ a) ^ b = 0 ^ b = b`
- 因此把数组中所有数字依次异或，成对出现的数字会两两抵消成 `0`，最后剩下的就是只出现一次的那个数字。
- 复杂度：遍历一次数组，`O(n)` 时间；只用一个变量累加异或结果，`O(1)` 空间，完美满足题目要求。

## 解法

利用异或运算「相同数抵消为 0、与 0 异或保持原值」的性质，把数组所有元素依次异或，成对数字相互抵消，最终剩下的即为只出现一次的数字。

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
const singleNumber = (nums) => {
  let result = 0;
  for (const num of nums) {
    result ^= num;
  }
  return result;
}

// 验证
console.log(singleNumber([2, 2, 1])); // 1
console.log(singleNumber([4, 1, 2, 1, 2])); // 4
console.log(singleNumber([1])); // 1
```

- **时间复杂度：** O(n)，其中 `n` 为数组长度，只需线性遍历一次。
- **空间复杂度：** O(1)，只使用了常量级的额外变量 `result`。

## 补充

- 进阶：如果数组中有两个数字各出现一次、其余均出现两次，如何用一个线性扫描找出来？可参考「260. 只出现一次的数字 III」（Single Number III），思路是先整体异或得到两数的异或值，再按某一位 `1` 将数组分成两组分别异或。
- 变形题「137. 只出现一次的数字 II」：每个元素出现三次、只有一个出现一次，此时异或无法直接抵消，需要借助位运算按位计数或状态机处理。
