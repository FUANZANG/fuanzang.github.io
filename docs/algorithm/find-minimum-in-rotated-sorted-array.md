# 旋转排序数组中的最小元素（Find Minimum in Rotated Sorted Array）

**难度：** Medium

## 题目描述

给定一个**升序排列**、且**不包含重复元素**的整数数组 `nums`，它在某个未知的下标位置进行了一次「旋转」操作。

所谓旋转，就是把数组最前面的若干元素整体搬到了数组的末尾。例如：
原始升序数组 `[0,1,2,4,5,6,7]` 若在下标 `3` 处旋转，就会变成 `[4,5,6,7,0,1,2]`。

请你找出并返回旋转后数组中**最小的那个元素**。

要求：时间复杂度尽量达到 **O(log n)**。

## 示例

**示例 1**
```
输入：nums = [3,4,5,1,2]
输出：1
解释：原数组 [1,2,3,4,5] 在下标 2 处旋转，最小值为 1。
```

**示例 2**
```
输入：nums = [4,5,6,7,0,1,2]
输出：0
解释：原数组 [0,1,2,4,5,6,7] 在下标 4 处旋转，最小值为 0。
```

**示例 3**
```
输入：nums = [11,13,15,17]
输出：11
解释：数组没有发生旋转（或相当于在下标 0 处旋转），最小值为 11。
```

**约束条件**
- `1 <= nums.length <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` 中的所有整数互不相同
- `nums` 原本是一个升序数组，经过一次旋转得到

## 提示 / 解题思路

1. **暴力法思路（仅用于对比）**：直接遍历整个数组，找出最小值，时间复杂度 O(n)。但这没有利用数组「原本有序 + 旋转」这一关键性质，题目要求更优的解法。

2. **关键观察**：旋转后的数组可以看成由「两段各自有序的升序子数组」拼接而成，并且**前半段的所有元素都大于后半段的所有元素**。最小值恰好是「第二段有序数组的第一个元素」，也就是两段的分界点。

3. **二分查找的切入点**：
   - 取区间 `[left, right]`，中点 `mid = Math.floor((left + right) / 2)`。
   - 比较 `nums[mid]` 与 `nums[right]` 的大小关系：
     - 如果 `nums[mid] < nums[right]`：说明 `[mid, right]` 这一段是**有序**的，最小值不可能落在这段的后半部分，可以把右边界收缩到 `mid`。
     - 如果 `nums[mid] > nums[right]`：说明旋转点（最小值）一定落在 `(mid, right]` 之间，把左边界移动到 `mid + 1`。
   - 这样每轮可以把搜索区间缩小一半，达到 O(log n)。

4. **边界思考**：
   - 当 `left === right` 时，区间只剩一个元素，它就是要找的最小值。
   - 也可以用 `nums[left]` 作为比较基准，但要注意处理「数组没有被旋转」的情况。

> 提示：先想清楚「为什么比较 `nums[mid]` 和 `nums[right]` 而不是和 `nums[left]` 更稳妥」，再动手写循环条件。试着用示例 1、2、3 手动走一遍二分过程，验证逻辑是否正确。

（本题为经典二分查找变形，不提供完整代码，鼓励先独立思考实现。）

## 解法

二分查找：比较 `nums[mid]` 与 `nums[right]`。若 `nums[mid] < nums[right]`，最小值在左半（含 mid）；否则在右半（不含 mid）。每轮区间减半，最终 `left` 即最小值。

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
const findMin = (nums) => {
  let left = 0,
    right = nums.length - 1
  while (left < right) {
    const mid = Math.floor((left + right) / 2)
    if (nums[mid] < nums[right]) right = mid
    else left = mid + 1
  }
  return nums[left]
}

// 验证
console.log(findMin([3, 4, 5, 1, 2])) // 1
console.log(findMin([4, 5, 6, 7, 0, 1, 2])) // 0
console.log(findMin([11, 13, 15, 17])) // 11
```

- **时间复杂度：** O(log n)，每轮区间减半。
- **空间复杂度：** O(1)，仅用几个指针变量。
