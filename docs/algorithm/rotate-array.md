# 旋转数组（Rotate Array）

**难度：** Medium

## 题目描述

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

请**原地**修改输入数组（使用 O(1) 的额外空间），不要返回新数组。数组长度 `n` 满足 `1 <= n <= 10^5`，元素范围 `-2^31 <= nums[i] <= 2^31 - 1`，且 `0 <= k <= 10^5`。

> 直观理解：把数组看成一个首尾相接的环，每个元素向右移动 `k` 步，超出的元素从数组头部"绕回来"。

### 约束条件

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

## 示例

```
示例 1：
输入：nums = [1,2,3,4,5,6,7], k = 3
输出：[5,6,7,1,2,3,4]
解释：向右轮转 1 步 -> [7,1,2,3,4,5,6]
     向右轮转 2 步 -> [6,7,1,2,3,4,5]
     向右轮转 3 步 -> [5,6,7,1,2,3,4]

示例 2：
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释：向右轮转 1 步 -> [99,-1,-100,3]
     向右轮转 2 步 -> [3,99,-1,-100]
```

## 提示 / 解题思路

**思路一：模拟轮转（简单但慢）**
每轮把最后一个元素暂存，其余元素整体后移一位，重复 `k % n` 次。时间复杂度 O(n·k)，在 `n = 10^5` 时容易超时，仅作为暴力基线。

**思路二：环状替换（O(n) 时间、O(1) 空间）**
把数组看作一个长度为 `n` 的环，元素 `i` 的新位置是 `(i + k) % n`。用 `count` 记录已移动的元素个数，从起点开始不断把元素"接力"推到下一个位置，直到回到起点时跳到 `start + 1` 继续，直到所有元素都被移动过。

**思路三：三次翻转（最简洁，推荐）**
关键观察：向右轮转 `k` 步，等价于把数组**后半段**（长度 `k % n`）整体搬到前面。于是可以：

1. 先翻转整个数组 `[1,2,3,4,5,6,7] -> [7,6,5,4,3,2,1]`；
2. 再翻转前 `k % n` 个元素 `[7,6,5] -> [5,6,7]`；
3. 最后翻转剩余部分 `[4,3,2,1] -> [1,2,3,4]`。

得到 `[5,6,7,1,2,3,4]`，正是答案。三次翻转都是原地交换，额外空间 O(1)。

**要点分析：**

- 当 `k` 大于数组长度时，`k %= n`（`k = n` 相当于不动，`k = n + 1` 相当于轮转 1 步）。
- 翻转区间用**双指针** `left`/`right` 向中间逼近交换，避免使用 `splice` 等 O(n) 额外开销。
- 注意 `k % n === 0` 时无需任何操作。

## 解法

思路：先整体翻转，再分别翻转前 `k % n` 个与剩余部分，三次翻转即完成原地轮转。

```javascript
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number[]} 原地修改后返回 nums，便于验证
 */
const rotate = (nums, k) => {
  const n = nums.length;
  k %= n;

  // 翻转 nums[left..right]（闭区间）
  const reverse = (left, right) => {
    while (left < right) {
      [nums[left], nums[right]] = [nums[right], nums[left]];
      left++;
      right--;
    }
  };

  reverse(0, n - 1); // 1. 翻转整个数组
  reverse(0, k - 1); // 2. 翻转前 k 个
  reverse(k, n - 1); // 3. 翻转剩余部分

  return nums;
};

// 验证
console.log(rotate([1, 2, 3, 4, 5, 6, 7], 3)); // [5,6,7,1,2,3,4]
console.log(rotate([-1, -100, 3, 99], 2));     // [3,99,-1,-100]
console.log(rotate([1, 2], 3));                // [2,1]（k 大于长度，取模后为 1）
console.log(rotate([1, 2, 3], 0));             // [1,2,3]（k 为 0 时不变）
```

- **时间复杂度：** O(n)
- **空间复杂度：** O(1)

## 补充

- **进阶挑战：** 尝试用「环状替换」思路实现（每次把元素移到 `(i + k) % n`），同样满足 O(n) 时间、O(1) 空间，但需要处理"提前回到起点"的边界。
- **易错点：** 忘记 `k %= n` 会越界；用 `slice` + `concat` 拼接虽然写法简单，但会额外开辟 O(n) 空间，不符合原地要求。
- **相关题目：** 变形题「189 的逆操作 —— 左轮转 k 位」可用同样三次翻转思路解决，只是翻转顺序调整为「前 k 个 → 剩余部分 → 整体」。
