# 最长连续递增子序列

**难度：** Easy

## 题目描述

给定一个未经排序的整数数组 `nums`，请找出其中**最长连续递增子序列**的长度，并返回该长度。

**连续递增子序列**是指子序列中相邻元素在原数组中也是相邻的，且每个元素都严格大于前一个元素。

> ⚠️ 注意：这里的"连续"指的是在原数组中位置连续，与"最长递增子序列 (LIS)"不同。

## 示例

```
输入: nums = [1, 3, 5, 4, 7]
输出: 3
解释: 最长连续递增子序列是 [1, 3, 5]，长度为 3。
     注意 [1, 3, 5, 7] 不是连续递增的，因为 4 打断了递增。
```

```
输入: nums = [2, 2, 2, 2, 2]
输出: 1
解释: 没有递增的子序列（需要严格递增），所以最长长度为 1（单个元素）。
```

## 提示 / 解题思路

1. **滑动窗口 / 一次遍历**：用一个变量记录当前连续递增序列的起点位置（或当前长度），遍历数组时比较相邻元素：
   - 如果 `nums[i] > nums[i-1]`，说明递增继续，当前长度 +1
   - 否则递增被打断，重置当前长度为 1

2. **维护最大值**：在遍历过程中，用另一个变量记录遇到的最大长度。

3. **边界情况**：
   - 空数组 → 返回 0
   - 只有一个元素 → 返回 1
   - 全部相等或递减 → 返回 1

4. **时间复杂度目标**：`O(n)`，只需遍历一次数组。
5. **空间复杂度目标**：`O(1)`，只需几个变量。

## 解法

一次遍历，维护当前连续递增长度与最大长度；当 nums[i] > nums[i-1] 时长度加一，否则重置为 1，并随时更新最大值。

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
const findLengthOfLCIS = (nums) => {
  if (nums.length === 0) return 0
  let maxLen = 1,
    curLen = 1
  for (let i = 1; i < nums.length; i++) {
    if (nums[i] > nums[i - 1]) curLen++
    else curLen = 1
    maxLen = Math.max(maxLen, curLen)
  }
  return maxLen
}

// 验证
console.log(findLengthOfLCIS([1, 3, 5, 4, 7])) // 3
console.log(findLengthOfLCIS([2, 2, 2, 2, 2])) // 1
```

- **时间复杂度：** O(n)，仅遍历一次数组。
- **空间复杂度：** O(1)。
