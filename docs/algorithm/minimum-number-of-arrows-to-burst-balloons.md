# 用最少数量的箭引爆气球（Minimum Number of Arrows to Burst Balloons）

**难度：** Medium

## 题目描述

一些球形气球贴在 XY 平面上，每个气球用其水平直径的起点与终点表示。由于气球是水平的，y 坐标无关紧要，只需要水平直径起点的 x 坐标（`x_start`）与终点的 x 坐标（`x_end`）即可。

箭头可以从 x 轴上的任意一点竖直向上射出。在 `x` 处射出的箭会引爆所有满足 `x_start <= x <= x_end` 的气球。箭的数量没有上限。一支箭射出后会无限向上飞行，引爆路径上的所有气球。

给定数组 `points`，其中 `points[i] = [x_start, x_end]` 表示第 i 个气球的水平直径，**返回引爆所有气球所需的最少箭数**。

### 约束条件

- `0 <= points.length <= 10^4`
- `points[i].length == 2`
- `-2^31 <= x_start < x_end <= 2^31 - 1`

## 示例

**示例 1：**

输入：
```
points = [[10,16],[2,8],[1,6],[7,12]]
```
输出：
```
2
```
解释：
- 一种方案：在 x = 6 处射出一支箭，引爆气球 [2,8] 和 [1,6]；再在 x = 11 处射出另一支箭，引爆其余两个气球。

**示例 2：**

输入：
```
points = [[1,2],[3,4],[5,6],[7,8]]
```
输出：
```
4
```
解释：
- 每个气球与其他气球都不重叠，需要 4 支箭才能全部引爆。

**示例 3：**

输入：
```
points = []
```
输出：
```
0
```
解释：
- 没有气球，不需要箭。

## 提示 / 解题思路

**贪心（按区间右端点排序）**：

本题是经典的「最少点覆盖全部区间」问题。关键在确定"一组重叠的区间需要多少支箭"。

**第 1 步：排序。** 把区间按右端点（`x_end`）升序排列。

**第 2 步：贪心扫描。** 第一支箭钉在第一个区间的右端点。之后依次看每个气球：若它的左端点超过了当前箭的位置，说明这支箭盖不到它，需要新射一支箭，并把它钉在这个区间的右端点；若左端点不超过箭的位置，则当前箭已经盖到它，无需新箭。

要点分析：

- 为什么按右端点排序？把箭钉在当前重叠组的"最小右端点"上，能覆盖尽可能多的后续区间；若按左端点排序则需沿途维护交点的右端，更绕。按右端点排序后，贪心选择直接落地为一趟扫描。
- 本题可看作「合并重叠区间」的对偶：合并问题统计区间并成几组，本题统计每组各需一支箭，答案相同。

## 解法

按右端点升序排序，第一支箭钉在首个区间右端点，遇到左端点超过当前箭位的区间就新射一支。

```javascript
/**
 * @param {number[][]} points
 * @return {number}
 */
const findMinArrowShots = (points) => {
  if (points.length === 0) return 0;
  const sorted = points.map((p) => [...p]).sort((a, b) => a[1] - b[1]);
  let arrows = 1;
  let arrowX = sorted[0][1]; // 第一支箭钉在第一个区间的右端点
  for (let i = 1; i < sorted.length; i++) {
    if (sorted[i][0] > arrowX) {
      arrows += 1;
      arrowX = sorted[i][1];
    }
  }
  return arrows;
};

// 验证
console.log(findMinArrowShots([[10,16],[2,8],[1,6],[7,12]])); // 2
console.log(findMinArrowShots([[1,2],[3,4],[5,6],[7,8]])); // 4
console.log(findMinArrowShots([])); // 0
```

- **时间复杂度：** O(n log n)
- **空间复杂度：** O(n)（拷贝排序时；原地排序可 O(1)）
