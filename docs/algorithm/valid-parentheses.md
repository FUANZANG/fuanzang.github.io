# 有效的括号（Valid Parentheses）

**难度：** Easy

## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

### 约束条件

- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

## 示例

**示例 1：**

```
输入：s = "()"
输出：true
```

**示例 2：**

```
输入：s = "()[]{}"
输出：true
```

**示例 3：**

```
输入：s = "(]"
输出：false
```

**示例 4：**

```
输入：s = "([)]"
输出：false
```

**示例 5：**

```
输入：s = "{[]}"
输出：true
```

## 提示 / 解题思路

在查看答案之前，建议先自己思考！以下是几个引导性问题：

1. **为什么栈是最自然的工具？**
   - 括号的匹配规则是「后出现的左括号必须先被闭合」——这正是**后进先出**（LIFO）的特征。
   - 遇到左括号时，我们还不知道它何时被闭合，只能「先存起来」；遇到右括号时，需要检查最近一个未闭合的左括号是否同类型。

2. **遍历时如何决策？**
   - 遇到**左括号**：入栈，等待匹配。
   - 遇到**右括号**：
     - 若栈为空 → 没有可匹配的左括号，直接返回 `false`。
     - 若栈顶不是对应的左括号 → 类型不匹配，返回 `false`。
     - 否则弹出栈顶，继续。

3. **结束条件是什么？**
   - 遍历结束后，栈必须为**空**。如果栈里还有残留的左括号，说明它们没有被闭合（例如 `"("`、`"(()"`）。

4. **可以用哈希表简化判断**
   - 用 `{ ')': '(', ']': '[', '}': '{' }` 记录「右括号 → 期望的左括号」映射，代码更简洁，也方便扩展更多括号类型。

5. **几个容易踩的坑**
   - 只判断数量相等是不够的：`"([)]"` 左右括号数量都匹配，但顺序错误，答案应为 `false`。
   - 不要忘记最后的「栈非空」检查：`"["` 应该返回 `false`。

伪代码思路：

```
stack = []
for c in s:
  if c 是左括号: stack.push(c)
  else:
    if stack 为空 或 stack.pop() != 对应的左括号: return false
return stack 为空
```

## 解法

遍历字符串，左括号入栈；遇到右括号时与栈顶比对，类型不符或栈为空则失败，最终要求栈恰好清空。

```javascript
/**
 * @param {string} s
 * @return {boolean}
 */
const isValid = (s) => {
  const stack = []
  // 右括号 -> 期望匹配的左括号
  const pairs = { ')': '(', ']': '[', '}': '{' }
  for (const c of s) {
    if (c === '(' || c === '[' || c === '{') {
      stack.push(c)
    } else {
      // 右括号：栈为空或栈顶类型不匹配，立即判定无效
      if (stack.length === 0 || stack.pop() !== pairs[c]) return false
    }
  }
  // 栈中不应残留未闭合的左括号
  return stack.length === 0
}

// 验证
console.log(isValid('()')) // true
console.log(isValid('()[]{}')) // true
console.log(isValid('(]')) // false
console.log(isValid('([)]')) // false
console.log(isValid('{[]}')) // true
console.log(isValid('(')) // false
console.log(isValid(']')) // false
```

- **时间复杂度：** O(n)，每个字符最多入栈、出栈各一次
- **空间复杂度：** O(n)，最坏情况（如 `"((((("`）栈中需要保存全部左括号

- **进阶挑战**：如果括号类型由用户输入自定义（例如 `"<>"`、`"【】"`），如何改造上面的代码？答案是把 `pairs` 映射表改成参数传入，判断逻辑完全不变。
- **变形题「32. 最长有效括号」（Longest Valid Parentheses）**：不再判断整个串是否有效，而是求最长的有效括号子串长度，需要用栈记录下标或改用动态规划，难度升为 Hard。
