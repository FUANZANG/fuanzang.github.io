# 最长湍流子数组（Longest Turbulent Subarray）

**难度：** Medium

## 题目描述

给定一个整数数组 `arr`，请返回数组中 **湍流子数组** 的最大长度。

**湍流子数组** 的定义是：子数组中相邻元素的比较符号**交替翻转**。具体来说，满足以下两种模式之一即可：

- 模式 A：`arr[i] > arr[i+1] < arr[i+2] > arr[i+3] < ...`（先降后升交替）
- 模式 B：`arr[i] < arr[i+1] > arr[i+2] < arr[i+3] > ...`（先升后降交替）

> 注意：子数组必须是**连续**的。如果两个相邻元素相等，则湍流中断。

## 示例

**示例 1：**

```
输入：arr = [9, 4, 2, 10, 7, 8, 8, 1, 4]
输出：5
解释：最长湍流子数组为 [2, 10, 7, 8, 1]
验证：2 < 10 > 7 < 8 > 1 ✓（符合模式 B）
```

**示例 2：**

```
输入：arr = [4, 8, 12, 16]
输出：2
解释：任意两个不同元素可组成长度为 2 的湍流子数组，
      如 [4, 8]（4 < 8）。无法形成更长的湍流序列。
```

**示例 3：**

```
输入：arr = [100]
输出：1
解释：单个元素本身就是长度为 1 的湍流子数组。
```

## 提示 / 解题思路

> ⚠️ 以下仅提供思路方向，**不包含完整代码**，请自行思考实现。

**提示 1：状态定义**

考虑使用**动态规划**。对于每个位置 `i`，你需要维护两个状态：
- `up`：以 `arr[i]` 结尾，且最后一步是**上升**（`arr[i-1] < arr[i]`）的最长湍流子数组长度。
- `down`：以 `arr[i]` 结尾，且最后一步是**下降**（`arr[i-1] > arr[i]`）的最长湍流子数组长度。

**提示 2：状态转移**

遍历数组，比较 `arr[i]` 与 `arr[i-1]`：
- 如果 `arr[i] > arr[i-1]`：当前是上升，那么它必须接在前一步是下降的序列后面 → `up = down + 1`，而 `down` 重置为 1。
- 如果 `arr[i] < arr[i-1]`：当前是下降，那么它必须接在前一步是上升的序列后面 → `down = up + 1`，而 `up` 重置为 1。
- 如果 `arr[i] === arr[i-1]`：湍流中断，`up` 和 `down` 都重置为 1。

**提示 3：记录答案**

在遍历过程中，用一个变量记录 `Math.max(up, down)` 的历史最大值即可。

**进阶思考：**
- 时间复杂度能否做到 O(n)？空间复杂度能否优化到 O(1)？
- 能否用**滑动窗口**的思路来解决这个问题？

## 解法

动态规划（空间 O(1)）：维护两个状态——`up` 表示以 `arr[i]` 结尾且最后一步为上升的最长湍流长度，`down` 表示最后一步为下降的最长长度。比较 `arr[i]` 与 `arr[i-1]`：若上升则 `up = down + 1`、否则 `down` 重置为 1；若下降则 `down = up + 1`、否则 `up` 重置为 1；相等则两者都重置为 1。答案取遍历过程中的 `max(up, down)`。

```javascript
/**
 * @param {number[]} arr
 * @return {number}
 */
const maxTurbulenceSize = (arr) => {
  let up = 1
  let down = 1
  let ans = 1
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] > arr[i - 1]) {
      up = down + 1
      down = 1
    } else if (arr[i] < arr[i - 1]) {
      down = up + 1
      up = 1
    } else {
      up = 1
      down = 1
    }
    ans = Math.max(ans, up, down)
  }
  return ans
}

// 验证
console.log(maxTurbulenceSize([9, 4, 2, 10, 7, 8, 8, 1, 4])) // 5
console.log(maxTurbulenceSize([4, 8, 12, 16])) // 2
console.log(maxTurbulenceSize([100])) // 1
```

- **时间复杂度：** O(n)，单次遍历。
- **空间复杂度：** O(1)，只用到常数个变量。
