# 最大子数组和

**难度：** Medium

## 题目描述

给定一个整数数组 `nums`，请你找出一个**连续子数组**（至少包含一个元素），使得其元素之和最大，并返回这个最大和。

**要求：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 示例

**输入：**
```javascript
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
```

**输出：**
```javascript
6
```

**解释：**
连续子数组 `[4, -1, 2, 1]` 的和最大，为 `6`。

**输入：**
```javascript
nums = [1]
```

**输出：**
```javascript
1
```

**输入：**
```javascript
nums = [-1, -2, -3]
```

**输出：**
```javascript
;-1
```

**解释：**
即使所有元素都是负数，也要选择最大的那个（即 `-1`）。

## 提示 / 解题思路

思考以下问题：
- 对于数组中的每个元素，我们有两个选择：**将其加入前面的子数组**，或者**从当前元素重新开始一个新的子数组**
- 如何决定选择哪个？
- 能否用一个变量记录"以当前元素结尾的最大子数组和"？

**关键状态转移：**
```
当前最大和 = max(当前元素本身, 当前元素 + 之前的最大和)
```

思考以下问题：
- 如果当前累加和变成负数，继续累加后面的元素还有意义吗？
- 什么时候应该"重置"累加和？

**核心思想：**
- 维护一个"当前和"，如果它变成负数就重置为 0
- 同时维护一个"最大和"，记录过程中出现的最大值

这道题是经典的 **Kadane's Algorithm** 问题。核心在于理解：**负数前缀不会让后面的和更大**，所以遇到负数前缀时应该果断舍弃。

## 解法

使用 Kadane 算法：维护「以当前元素结尾的最大子数组和」`current`，每一步取 `max(当前元素, current + 当前元素)`，并用 `maxSoFar` 记录历史最大值。负数前缀只会拖累后续和，因此一旦 `current` 为负就自然被「当前元素本身」取代（即重置起点）。

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
const maxSubArray = (nums) => {
  let maxSoFar = nums[0]
  let current = nums[0]
  for (let i = 1; i < nums.length; i++) {
    current = Math.max(nums[i], current + nums[i])
    maxSoFar = Math.max(maxSoFar, current)
  }
  return maxSoFar
}

// 验证
console.log(maxSubArray([-2, 1, -3, 4, -1, 2, 1, -5, 4])) // 6
console.log(maxSubArray([1])) // 1
console.log(maxSubArray([-1, -2, -3])) // -1
```

- **时间复杂度：** O(n)，单次遍历。
- **空间复杂度：** O(1)，只用到常数个变量。

## 补充

### 边界情况考虑

1. 数组只有一个元素
2. 所有元素都是负数
3. 所有元素都是正数
4. 数组包含 0

### 进阶挑战

如果你已经解决了 O(n) 的问题，尝试思考：
- 如果数组是**环形**的（首尾相连），如何求解？
- 如何返回**最大子数组的起始和结束位置**？
