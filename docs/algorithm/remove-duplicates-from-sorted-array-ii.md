# 移除有序数组中的重复项 II

**难度：** Medium

## 题目描述

**题目描述：**

给你一个 **非严格递增排列** 的整数数组 `nums`，请你删除其中的重复元素，使得数组中 **每个元素最多出现两次**。

删除重复元素后，数组的前半部分（即 `k` 个元素的区间）应包含该数组中所有 **唯一出现最多两次的元素**。

你不需要像数组那样为其他数组中不可出现的元素保留额外的空间。你的解决方案必须 **原地修改** 输入数组，并在 **O(1)** 额外空间的条件下完成。

形式上，假设按照此约定：

- `nums` 的长度为 `n`。
- `k` 个元素的区间 `[0, k - 1]` 应包含数组中所有唯一出现最多两次的元素，且 **顺序与原数组相同**。
- `k` 是符合条件的最大长度。
- `[0, k - 1]` 范围外的所有元素（即 `[k, n - 1]`）并不需要考虑。

**返回** `k`。

**注意：** 不要使用 `Array.prototype.splice` 等数组方法改变数组的长度，必须在原有数组中进行就地修改。

**示例 1：**

```
输入：nums = [1,1,1,2,2,3]
输出：k = 5, nums = [1,1,2,2,3,...]
解释：数组中每个元素最多出现两次，因此返回 5，nums 的前 5 个元素是 [1,1,2,2,3]。
```

**示例 2：**

```
输入：nums = [0,0,1,1,1,1,2,2,3,3,3]
输出：k = 9, nums = [0,0,1,1,2,2,3,3,...]
解释：数组中每个元素至少出现一次，最多出现三次的是 1。删除多余的 1 后，
      返回 9，nums 的前 9 个元素是 [0,0,1,1,2,2,3,3]。
```

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 非严格递增排列

**解题思路 / 提示：**

1. **双指针法**：使用一个慢指针 `k` 表示「有效写入位置」，另一个快指针 `i` 遍历整个数组。慢指针 `k` 永远指向下一个「应该被写入」的元素位置。

2. **核心判断**：当 `i` 遍历到 `nums[i]` 时，只有当 `nums[i]` **不等于** `nums[k - 2]` 时，才应该将 `nums[i]` 写入到 `nums[k]` 并移动 `k`。为什么是 `k - 2` 而不是 `k - 1` 呢？想一想「最多出现两次」和「有序数组」这两个关键字。

3. **边界情况**：初始时 `k = 0`，数组长度小于等于 2 时，无需任何处理，直接返回原数组长度即可。

4. **原地修改**：每次满足条件时，执行 `nums[k] = nums[i]; k++` 即可。最终返回 `k`。

> **提示**：想象一下，写入区 `[0, k - 1]` 内部的数据已经满足「每个元素最多出现两次」。如果 `nums[i]` 还没被放进写入区，如何判断它是否已经在写入区出现过了两次？答案是：因为数组 **有序**，所以只需比较 `nums[i]` 与写入区末尾的「两个前位置」的元素。

**复杂度分析：**

- **时间复杂度**：O(n) — 快指针遍历一次。
- **空间复杂度**：O(1) — 仅使用常数额外空间。

## 解法

双指针原地修改：慢指针 `k` 指向「下一个应写入的位置」，快指针 `i` 遍历数组。因为数组有序且「最多保留两次」，只要 `nums[i] !== nums[k-2]` 就写入 `nums[k]` 并右移 `k`；前两个元素恒保留。最终返回 `k`。

> 注意：源文件「示例 2」写明 `k = 9`，但其列出的数组 `[0,0,1,1,2,2,3,3]` 只有 8 个元素，且按「最多出现两次」规则 `3` 出现 3 次只能保留 2 个，正确结果应为 `k = 8`（前 8 个元素为 `[0,0,1,1,2,2,3,3]`）。下方验证以正确结果为准。

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
const removeDuplicates = (nums) => {
  const n = nums.length
  if (n <= 2) return n
  let k = 2
  for (let i = 2; i < n; i++) {
    if (nums[i] !== nums[k - 2]) {
      nums[k] = nums[i]
      k++
    }
  }
  return k
}

// 验证
const a = [1, 1, 1, 2, 2, 3]
console.log(removeDuplicates(a), a.slice(0, 5)) // 5 [1,1,2,2,3]
const b = [0, 0, 1, 1, 1, 1, 2, 2, 3, 3, 3]
console.log(removeDuplicates(b), b.slice(0, 8)) // 8 [0,0,1,1,2,2,3,3]
```

- **时间复杂度：** O(n)
- **空间复杂度：** O(1)
