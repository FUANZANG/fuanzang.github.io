# 不同子序列（Distinct Subsequences）

**难度：** Hard

## 题目描述

给定两个字符串 `s` 和 `t`，返回 `s` 中等于 `t` 的**不同子序列**的数目。

子序列是指从原字符串中删除一些（也可以不删除）字符，且不改变剩余字符的相对位置，从而得到的新字符串。例如 `"ACE"` 是 `"ABCDE"` 的子序列，而 `"AEC"` 不是。

这里「不同」指的是删除位置的方案数：即使两个方案最终得到的字符序列相同，只要它们由 `s` 中不同的位置构成，就记为两种。

### 约束条件

- `1 <= s.length, t.length <= 1000`
- `s` 和 `t` 由英文字母组成
- 测试用例保证答案在 32 位有符号整数范围内

## 示例

示例 1：

```
输入：s = "rabbbit", t = "rabbit"
输出：3
解释：
有 3 种方式从 s 中删出 "rabbit"：
  rabb b it   （第 1 个 b）
  ra b bbit   （第 2 个 b）
  rab b bit   （第 3 个 b）
```

示例 2：

```
输入：s = "babgbag", t = "bag"
输出：5
解释：
有 5 种方式从 s 中删出 "bag"，对应选取的字符位置各不相同。
```

## 提示 / 解题思路

> 💡 **不要急着看提示！先独立思考 15~20 分钟，实在没思路再往下看。**

提示 1：这是一个典型的**字符串动态规划**问题，状态设计是核心。
定义 `dp[i][j]` = `s` 的前 `i` 个字符中，等于 `t` 的前 `j` 个字符的不同子序列数目。

提示 2：写出状态转移。对当前字符 `s[i-1]` 与目标字符 `t[j-1]`：
- 若 `s[i-1] === t[j-1]`：既可以用它（贡献 `dp[i-1][j-1]` 种），也可以不用（继承 `dp[i-1][j]` 种），所以 `dp[i][j] = dp[i-1][j] + dp[i-1][j-1]`。
- 若 `s[i-1] !== t[j-1]`：它无法匹配 `t[j-1]`，只能不用，`dp[i][j] = dp[i-1][j]`。

提示 3：边界与初始化。
- `dp[i][0] = 1`（任意 `s` 前缀匹配空串 `t` 恒有 1 种：全删掉）
- `dp[0][j>0] = 0`（空串 `s` 匹配非空 `t` 为 0）

提示 4：空间优化。
转移只依赖上一行 `i-1`，可压成一维 `dp[j]`。注意 `j` 必须**倒序**遍历（从 `n` 到 `1`），这样更新 `dp[j]` 时 `dp[j-1]` 还是处理 `s[i]` 之前的旧值，避免同一字符被重复使用。

## 解法

一维 DP：`dp[j]` 表示已处理的 `s` 前缀下、等于 `t` 前 `j` 个字符的子序列数，对每个 `s[i]` 倒序更新 `j`，空间降到 `O(n)`。

```javascript
/**
 * @param {string} s
 * @param {string} t
 * @return {number}
 */
const numDistinct = (s, t) => {
  const m = s.length;
  const n = t.length;
  // dp[j]：已处理的 s 前缀中，等于 t 前 j 个字符的不同子序列数
  const dp = new Array(n + 1).fill(0);
  dp[0] = 1;

  for (let i = 0; i < m; i++) {
    // 倒序遍历，保证 dp[j-1] 取到的是处理 s[i] 之前的值
    for (let j = n; j >= 1; j--) {
      if (s[i] === t[j - 1]) {
        dp[j] += dp[j - 1];
      }
    }
  }

  return dp[n];
};

// 验证
console.log(numDistinct("rabbbit", "rabbit")); // 3
console.log(numDistinct("babgbag", "bag")); // 5
```

- **时间复杂度：** O(m·n)，m、n 分别为 `s`、`t` 的长度
- **空间复杂度：** O(n)，一维 DP 只保留长度为 `n+1` 的数组
