# 买卖股票的最佳时机（Best Time to Buy and Sell Stock）

**难度：** Easy

## 题目描述

给定一个数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。

你只能选择**某一天买入**，并在**未来的某一天卖出**（必须先买入后卖出，且只能完成一笔交易）。设计算法计算所能获取的最大利润。如果无论如何都无法获利，返回 `0`。

### 约束条件

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

## 示例

**示例 1：**

```text
输入：prices = [7, 1, 5, 3, 6, 4]
输出：5
解释：在第 2 天（价格 = 1）买入，在第 5 天（价格 = 6）卖出，利润 = 6 - 1 = 5。
      注意：利润不能是 7 - 1 = 6，因为卖出价格必须高于买入价格；同时你不能在买入之前卖出。
```

**示例 2：**

```text
输入：prices = [7, 6, 4, 3, 1]
输出：0
解释：价格一路下跌，不存在任何买入后能以更高价卖出的时机，因此最大利润为 0。
```

## 提示 / 解题思路

- **暴力法**：枚举所有「买入在第 i 天、卖出在第 j 天（j > i）」的组合，取最大差值。时间复杂度 O(n²)，当 `n` 达到 10⁵ 时会超时，不可取。
- **核心观察**：对每一天 `i` 作为卖出日，能获得的最大利润 = `prices[i] - 左侧出现过的最低价格`。我们只需要在遍历时维护这个「历史最低买入价」即可，无需回看。
- **一次遍历**：
  1. 用 `minPrice` 记录遍历到当前为止遇到过的最低价格（初始设为无穷大）。
  2. 每遇到一个 `price`，先尝试更新 `minPrice`；再用 `price - minPrice` 更新全局最大利润 `maxProfit`。
  3. 这样每个位置都等价于「以当日卖出、用历史最低价买入」的最优情况。
- **为什么不用二维 DP**：本题只能做一次交易，状态极简（持有/不持有且只能买一次卖一次），单变量贪心即可覆盖，不需要完整状态机。

## 解法

一句话思路：从左到右扫描，维护「截至当前遇到的最低买入价」，用当天价格减去该最低价，不断更新全局最大利润。

```javascript
/**
 * @param {number[]} prices
 * @return {number}
 */
const maxProfit = (prices) => {
  let minPrice = Infinity;
  let maxProfit = 0;
  for (const price of prices) {
    if (price < minPrice) {
      minPrice = price;
    }
    const profit = price - minPrice;
    if (profit > maxProfit) {
      maxProfit = profit;
    }
  }
  return maxProfit;
}

// 验证
console.log(maxProfit([7, 1, 5, 3, 6, 4])); // 5
console.log(maxProfit([7, 6, 4, 3, 1])); // 0
```

- **时间复杂度：** O(n)，只遍历数组一次。
- **空间复杂度：** O(1)，只用到常数个额外变量。

## 补充

- 变形题「122. 买卖股票的最佳时机 II」：允许多次交易（但同一天不能同时买卖），可用「所有上升段累加」或贪心处理。
- 变形题「188. 买卖股票的最佳时机 IV」：最多完成 `k` 笔交易，需用状态机 DP（持有 / 不持有 × 交易次数），是本题的通用推广。
