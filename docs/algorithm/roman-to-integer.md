# 罗马数字转整数（Roman to Integer）

**难度：** Easy

## 题目描述

罗马数字由以下七个不同的符号表示：

| 符号 | 值 |
|------|----|
| I    | 1  |
| V    | 5  |
| X    | 10 |
| L    | 50 |
| C    | 100|
| D    | 500|
| M    | 1000|

例如，数字 `2` 写作 `II`（两个 `I` 相加），`12` 写作 `XII`（即 `X + II`），`27` 写作 `XXVII`（即 `XX + V + II`）。

罗马数字通常从左到右按从大到小的顺序排列。但也有例外：`4` 不写作 `IIII`，而是写作 `IV`——因为 `I` 在 `V` 之前，表示减去 `1`，得到 `4`。同理 `9` 写作 `IX`。减法规则共有六种情况：

- `I` 可以放在 `V`（5）和 `X`（10）之前，表示 `4` 和 `9`；
- `X` 可以放在 `L`（50）和 `C`（100）之前，表示 `40` 和 `90`；
- `C` 可以放在 `D`（500）和 `M`（1000）之前，表示 `400` 和 `900`。

给定一个罗马数字字符串 `s`，将其转换为对应的整数。

### 约束条件

- `1 <= s.length <= 15`
- `s` 仅包含字符 `'I'`、`'V'`、`'X'`、`'L'`、`'C'`、`'D'`、`'M'`
- 题目保证 `s` 是一个有效的罗马数字，且对应值在 `[1, 3999]` 范围内

## 示例

**示例 1：**

```text
输入：s = "III"
输出：3
解释：III = 3。
```

**示例 2：**

```text
输入：s = "LVIII"
输出：58
解释：L = 50, V = 5, III = 3。
```

**示例 3：**

```text
输入：s = "MCMXCIV"
输出：1994
解释：M = 1000, CM = 900, XC = 90, IV = 4。
```

## 提示 / 解题思路

核心观察：**从左到右遍历时，只要当前符号的值小于它右边符号的值，就把当前值「减去」；否则「加上」。** 这是因为减法规则（IV、IX、XL、XC、CD、CM）恰好就是「小的符号出现在大的符号左边」的情况。

- 先建立一个符号到数值的映射表 `map`。
- 遍历字符串，对每个位置 `i`：
  - 取当前值 `current = map[s[i]]`，下一个值 `next = map[s[i + 1]]`（末尾无下一个时为 `undefined`）。
  - 若 `next` 存在且 `current < next`，说明遇到减法规则，`result -= current`；
  - 否则（含末尾）`result += current`。
- 遍历结束后 `result` 即为答案。

要点：无需特判六种减法组合，一个「当前是否小于下一个」的比较就覆盖了所有情况。

## 解法

从左到右扫描，当前值小于下一个值时减去，否则加上，一次遍历即可得到结果。

```javascript
/**
 * @param {string} s
 * @return {number}
 */
const romanToInt = (s) => {
  // 符号 -> 数值 映射
  const map = { I: 1, V: 5, X: 10, L: 50, C: 100, D: 500, M: 1000 };
  let result = 0;
  for (let i = 0; i < s.length; i++) {
    const current = map[s[i]];
    const next = map[s[i + 1]];
    // 遇到减法规则（当前值小于下一个值）则减去，否则加上
    if (next && current < next) {
      result -= current;
    } else {
      result += current;
    }
  }
  return result;
}

// 验证
console.log(romanToInt("III")); // 3
console.log(romanToInt("LVIII")); // 58
console.log(romanToInt("MCMXCIV")); // 1994
```

- **时间复杂度：** O(n)，其中 n 为字符串长度，只需遍历一次。
- **空间复杂度：** O(1)，仅使用固定大小的映射表与若干变量。
