# 合并两个有序数组（Merge Sorted Array）

**难度：** Easy

## 题目描述

给你两个 **非递减排序** 的整数数组 `nums1` 和 `nums2`，以及两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中有效元素的个数。

`nums1` 的长度为 `m + n`，其中前 `m` 个元素表示应合并的部分，后 `n` 个元素为 `0`（应被忽略）。

请你将 `nums2` 合并到 `nums1` 中，使得合并后的数组同样保持 **非递减排序**。

**要求：** 请在 **原地** 修改 `nums1`，不要返回新的数组。

### 约束条件

- `nums1.length == m + n`
- `nums2.length == n`
- `0 <= m, n <= 200`
- `1 <= m + n <= 200`
- `-10^9 <= nums1[i], nums2[j] <= 10^9`
- `nums1` 和 `nums2` 都是 **非递减排序** 的

## 示例

**输入：**

```
nums1 = [1, 2, 3, 0, 0, 0], m = 3
nums2 = [2, 5, 6],       n = 3
```

**输出：**

```
[1, 2, 2, 3, 5, 6]
```

**解释：** 合并后数组为 `[1, 2, 2, 3, 5, 6]`。

**输入：**

```
nums1 = [1], m = 1
nums2 = [],              n = 0
```

**输出：**

```
[1]
```

**解释：** 不需要合并任何元素。

**输入：**

```
nums1 = [0], m = 0
nums2 = [1], n = 1
```

**输出：**

```
[1]
```

## 提示 / 解题思路

如果从前往后合并，当把 `nums2` 的元素放入 `nums1` 时，可能会覆盖掉 `nums1` 中尚未处理的元素。这会导致数据丢失。

既然 `nums1` 的末尾有 `n` 个多余的 `0` 空间，我们可以 **从后往前** 合并：

- 设置三个指针：
  - `p1` 指向 `nums1` 的有效元素末尾（即索引 `m - 1`）
  - `p2` 指向 `nums2` 的末尾（即索引 `n - 1`）
  - `p` 指向 `nums1` 的最后一个位置（即索引 `m + n - 1`）

- 每次比较 `nums1[p1]` 和 `nums2[p2]`，将较大的那个放到 `nums1[p]` 的位置，然后对应指针前移。

- 当 `p2 < 0` 时说明 `nums2` 已经全部合并完毕；如果此时 `p1 >= 0`，说明 `nums1` 还有剩余元素——但这些元素本来就在正确位置，无需处理。

- 当 `m = 0` 时，`nums1` 中没有有效元素，直接将 `nums2` 全部拷贝即可。
- 当 `n = 0` 时，`nums2` 为空，无需操作。
- 当 `nums1[p1] === nums2[p2]` 时，放哪个都可以（保持稳定性不影响结果）。

## 解法

从后往前双指针原地合并：

```javascript
/**
 * @param {number[]} nums1
 * @param {number} m
 * @param {number[]} nums2
 * @param {number} n
 * @return {void} 原地修改 nums1，不返回新数组
 */
const merge = (nums1, m, nums2, n) => {
  let p1 = m - 1 // nums1 有效元素末位
  let p2 = n - 1 // nums2 末位
  let p = m + n - 1 // 写入位置（nums1 物理末位）

  while (p2 >= 0) {
    // nums2 还有元素就继续
    if (p1 >= 0 && nums1[p1] > nums2[p2]) {
      nums1[p] = nums1[p1]
      p1--
    } else {
      nums1[p] = nums2[p2]
      p2--
    }
    p--
  }
  // p1 >= 0 时剩余元素本就在正确位置，无需处理
}

// 验证
let a = [1, 2, 3, 0, 0, 0],
  b = [2, 5, 6]
merge(a, 3, b, 3)
console.log(a) // [1, 2, 2, 3, 5, 6]
```

- **时间复杂度：** O(m + n)，每个元素最多访问一次
- **空间复杂度：** O(1)，原地修改
