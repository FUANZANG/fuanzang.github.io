# 不同路径（Unique Paths）

**难度：** Medium

## 题目描述

一个机器人位于一个 `m x n` 网格的左上角（起始点标记为 "Start"）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（终点标记为 "Finish"）。

问总共有多少条不同的路径？

### 约束条件

- `1 <= m, n <= 100`
- 题目答案保证小于等于 `2 * 10^9`

## 示例

**示例 1：**

```
输入：m = 3, n = 7
输出：28
```

**示例 2：**

```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角：
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

## 提示 / 解题思路

这是一道经典的动态规划题目。

- **状态定义**：`dp[i][j]` 表示从起点到达网格 `(i, j)` 的不同路径数。
- **状态转移**：因为只能向下或向右走，所以到达 `(i, j)` 只能从 `(i-1, j)`（上方）或 `(i, j-1)`（左方）走过来，即 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。
- **初始条件**：第一行和第一列的格子都只有一条路径到达（只能一直向右或一直向下），所以 `dp[0][j] = dp[i][0] = 1`。

由于每个状态只依赖上方和左方，可以优化空间复杂度为 O(n)，使用一维滚动数组。

## 解法

动态规划，一维滚动数组优化空间。

```javascript
/**
 * @param {number} m
 * @param {number} n
 * @return {number}
 */
const uniquePaths = (m, n) => {
  const dp = new Array(n).fill(1);

  for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
      dp[j] += dp[j - 1];
    }
  }

  return dp[n - 1];
};

// 验证
console.log(uniquePaths(3, 7)); // 28
console.log(uniquePaths(3, 2)); // 3
console.log(uniquePaths(1, 1)); // 1
console.log(uniquePaths(5, 5)); // 70
```

- **时间复杂度：** O(m × n)
- **空间复杂度：** O(n)

## 补充

- 若网格中存在障碍物（某些格子不可通过），则变为 [不同路径 II](https://leetcode.cn/problems/unique-paths-ii/)，只需在状态转移时跳过障碍格即可。
- 本题也可以用组合数学求解：总共需要走 `(m-1)` 次向下和 `(n-1)` 次向右，即从 `(m+n-2)` 步中选 `(m-1)` 步向下，答案为 C(m+n-2, m-1)。
