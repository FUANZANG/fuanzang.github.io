# 多数元素（Majority Element）

**难度：** Easy

## 题目描述

给定一个大小为 `n` 的数组 `nums`，返回其中的**多数元素**。多数元素是指在数组中出现次数**严格大于** `⌊n / 2⌋` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

### 约束条件

- `n == nums.length`
- `1 <= n <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`
- 多数元素总是存在于数组中

## 示例

示例 1：

```
输入：nums = [3,2,3]
输出：3
```

示例 2：

```
输入：nums = [2,2,1,1,1,2,2]
输出：2
```

## 提示 / 解题思路

最朴素的做法是哈希表统计频次，或先排序后取中位（因为多数元素出现次数过半，排序后必然落在正中间）。但这两种分别需要 `O(n)` 额外空间或 `O(n log n)` 时间。

更优的解法是 **Boyer–Moore 投票算法**：核心思想是「抵消」。由于多数元素出现次数超过一半，我们可以维护一个候选元素 `candidate` 和计数器 `count`：

- 若 `count == 0`，将当前元素设为新的候选 `candidate`，`count = 1`；
- 否则，若当前元素等于 `candidate`，`count += 1`；否则 `count -= 1`（不同元素相互抵消）。

遍历结束后，`candidate` 就是多数元素。因为多数元素出现次数比其他所有元素加起来还多，无论怎样的抵消顺序，最后剩下的一定是它。该算法只需一次遍历、常数空间。

> 注意：该算法之所以成立，依赖「多数元素一定存在」这一前提；若不能保证，最后还需再扫一遍数组验证候选是否真的过半。

## 解法

一句话思路：用 Boyer–Moore 投票算法，靠「相同 +1、不同 -1、清零换人」的抵消规则，在一次遍历中找出出现次数过半的候选元素。

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
const majorityElement = (nums) => {
  let candidate = null;
  let count = 0;

  for (const num of nums) {
    if (count === 0) {
      candidate = num;
      count = 1;
    } else if (num === candidate) {
      count += 1;
    } else {
      count -= 1;
    }
  }

  return candidate;
}

// 验证
console.log(majorityElement([3, 2, 3])); // 期望输出: 3
console.log(majorityElement([2, 2, 1, 1, 1, 2, 2])); // 期望输出: 2
```

- **时间复杂度：** O(n)，只需对数组线性遍历一次。
- **空间复杂度：** O(1)，仅用常数个变量，未借助额外数据结构。

## 补充

- 进阶：如果题目**不保证**多数元素一定存在（例如返回「不存在」），可在投票后追加一次遍历统计 `candidate` 的真实出现次数并判断是否 `> ⌊n/2⌋`。
- 类似思路可迁移到「数组中找一个出现次数超过 1/3 的元素」（摩尔投票的扩展，需同时维护两个候选）。
- 相关题目：变形题「229. 求众数 II（Boyer–Moore 扩展，找出现次数超过 ⌊n/3⌋ 的所有元素）」。
