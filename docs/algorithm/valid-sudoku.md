# 有效的数独（Valid Sudoku）

**难度：** Medium

## 题目描述

请你判断一个 `9 x 9` 的数独是否有效。只需要根据以下规则，验证已经填入的数字是否有效即可：

1. 数字 `1-9` 在每一行只能出现一次。
2. 数字 `1-9` 在每一列只能出现一次。
3. 数字 `1-9` 在每一个以粗实线分隔的 `3x3` 宫内只能出现一次。

注意：

- 一个有效的数独（部分填充）不一定是可解的。
- 只需要根据以上规则，验证已经填入的数字是否有效即可。
- 空白格用 `'.'` 表示。

### 约束条件

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` 是一位数字 `1-9` 或者 `'.'`

## 示例

**示例 1：**

```
输入：
board = [
  ["5","3",".",".","7",".",".",".","."],
  ["6",".",".","1","9","5",".",".","."],
  [".","9","8",".",".",".",".","6","."],
  ["8",".",".",".","6",".",".",".","3"],
  ["4",".",".","8",".","3",".",".","1"],
  ["7",".",".",".","2",".",".",".","6"],
  [".","6",".",".",".",".","2","8","."],
  [".",".",".","4","1","9",".",".","5"],
  [".",".",".",".","8",".",".","7","9"]
]
输出：true
```

解释：除了已经填入的数字外，空白格用 `'.'` 表示，已填入的数字满足数独规则。

**示例 2：**

```
输入：
board = [
  ["8","3",".",".","7",".",".",".","."],
  ["6",".",".","1","9","5",".",".","."],
  [".","9","8",".",".",".",".","6","."],
  ["8",".",".",".","6",".",".",".","3"],
  ["4",".",".","8",".","3",".",".","1"],
  ["7",".",".",".","2",".",".",".","6"],
  [".","6",".",".",".",".","2","8","."],
  [".",".",".","4","1","9",".",".","5"],
  [".",".",".",".","8",".",".","7","9"]
]
输出：false
```

解释：第一行和第一列都出现了数字 `8`，违反了数独规则。

## 提示 / 解题思路

**思路：一次遍历 + 哈希集合**

核心难点在于如何确定某个数字属于哪个 `3x3` 子盒子。对于位置 `(row, col)`，其所在的盒子编号为：

```
boxIndex = Math.floor(row / 3) * 3 + Math.floor(col / 3)
```

这样就把 9 个 `3x3` 盒子编为了 `0-8` 号。

遍历每个单元格，如果非空，则检查该数字是否已在对应的行集合、列集合、盒子集合中出现过。若出现过则无效；否则加入三个集合。

**优化：使用位运算**

可以用一个 9 位二进制数来记录某个数字是否已在某行/列/盒子中出现过，用位运算 `&` 检查、`|` 标记，比 Set 更省空间且更快。

## 解法

一次遍历，用三组哈希集合分别记录每行、每列、每盒子已出现的数字。

```javascript
/**
 * @param {character[][]} board
 * @return {boolean}
 */
const isValidSudoku = (board) => {
  const rows = Array.from({ length: 9 }, () => new Set());
  const cols = Array.from({ length: 9 }, () => new Set());
  const boxes = Array.from({ length: 9 }, () => new Set());

  for (let r = 0; r < 9; r++) {
    for (let c = 0; c < 9; c++) {
      const val = board[r][c];
      if (val === '.') continue;

      const boxIndex = Math.floor(r / 3) * 3 + Math.floor(c / 3);

      if (rows[r].has(val) || cols[c].has(val) || boxes[boxIndex].has(val)) {
        return false;
      }

      rows[r].add(val);
      cols[c].add(val);
      boxes[boxIndex].add(val);
    }
  }

  return true;
};

// 验证示例 1
const board1 = [
  ["5","3",".",".","7",".",".",".","."],
  ["6",".",".","1","9","5",".",".","."],
  [".","9","8",".",".",".",".","6","."],
  ["8",".",".",".","6",".",".",".","3"],
  ["4",".",".","8",".","3",".",".","1"],
  ["7",".",".",".","2",".",".",".","6"],
  [".","6",".",".",".",".","2","8","."],
  [".",".",".","4","1","9",".",".","5"],
  [".",".",".",".","8",".",".","7","9"]
];
console.log(isValidSudoku(board1)); // true

// 验证示例 2
const board2 = [
  ["8","3",".",".","7",".",".",".","."],
  ["6",".",".","1","9","5",".",".","."],
  [".","9","8",".",".",".",".","6","."],
  ["8",".",".",".","6",".",".",".","3"],
  ["4",".",".","8",".","3",".",".","1"],
  ["7",".",".",".","2",".",".",".","6"],
  [".","6",".",".",".",".","2","8","."],
  [".",".",".","4","1","9",".",".","5"],
  [".",".",".",".","8",".",".","7","9"]
];
console.log(isValidSudoku(board2)); // false
```

- **时间复杂度：** O(1) — 固定遍历 81 个单元格，常数级别。
- **空间复杂度：** O(1) — 三组各 9 个 Set，每个最多存 9 个元素，常数级别。
