# 有序数组的平方

**难度：** Easy

## 题目描述

给你一个按 **非递减顺序** 排好序的整数数组 `nums`，请你重新排列返回 **每个数平方后** 的数组，并要求同样按 **非递减顺序** 排列。

> 提示：注意 `nums` 中可能包含负数。在平方之后，负数会变成正数，从而打破原有的顺序。

## 示例

**示例 1：**

```
输入：nums = [-4,-1,0,3,10]
输出：[0,1,9,16,100]
解释：平方后，数组变为 [16,1,0,9,100]，排序后为 [0,1,9,16,100]
```

**示例 2：**

```
输入：nums = [-7,-3,2,3,11]
输出：[4,9,9,49,121]
```

## 提示 / 解题思路

> ⚠️ **请不要直接翻看答案代码**，先尝试自己思考哟～

1. **朴素想法**：先平方再排序 —— 时间复杂度 `O(n log n)`，能通过，但不是最优。

2. **关键观察**：原数组是有序的，但 **负数的平方** 可能会很大。也就是说，平方后最大值 **一定** 来自数组的 **最左端**（最小的负数）或 **最右端**（最大的正数）。

3. **双指针优化**：
   - 设置两个指针 `left` 指向数组起始，`right` 指向数组末尾。
   - 每次比较 `nums[left]²` 与 `nums[right]²`，把较大的那个放到结果数组的 **末尾**，然后移动相应的指针。
   - 结果数组从后往前填充，最终就得到了有序结果。

4. **时间复杂度**：`O(n)` —— 每个元素只遍历一次。  
   **空间复杂度**：`O(n)` —— 用于存放结果数组。

## 解法

双指针：原数组非递减，平方后的最大值一定来自最左（最小负数）或最右（最大正数）。比较两端平方值，把较大的从结果数组末尾往前填，左右指针向中间靠拢，一次遍历即得有序结果。

```javascript
/**
 * @param {number[]} nums
 * @return {number[]}
 */
const sortedSquares = (nums) => {
  const n = nums.length
  const res = new Array(n)
  let left = 0,
    right = n - 1,
    pos = n - 1
  while (left <= right) {
    const lsq = nums[left] * nums[left]
    const rsq = nums[right] * nums[right]
    if (lsq > rsq) {
      res[pos--] = lsq
      left++
    } else {
      res[pos--] = rsq
      right--
    }
  }
  return res
}

// 验证
console.log(sortedSquares([-4, -1, 0, 3, 10])) // [0,1,9,16,100]
console.log(sortedSquares([-7, -3, 2, 3, 11])) // [4,9,9,49,121]
```

- **时间复杂度：** O(n)
- **空间复杂度：** O(n)
