# 整数反转（Reverse Integer）

**难度：** Medium

## 题目描述

给你一个 32 位的有符号整数 `x`，返回将 `x` 中数字部分反转后的结果。

如果反转后整数超过 32 位的有符号整数的范围 `[−2^31, 2^31 − 1]`，就返回 0。

**假设环境不允许存储 64 位整数（有符号或无符号）。**

### 约束条件

- `-2^31 <= x <= 2^31 - 1`

## 示例

### 示例 1

```
输入：x = 123
输出：321
```

### 示例 2

```
输入：x = -123
输出：-321
```

### 示例 3

```
输入：x = 120
输出：21
```

### 示例 4

```
输入：x = 1534236469
输出：0
解释：反转后得到 9646324351，超过了 32 位有符号整数范围，因此返回 0。
```

## 提示 / 解题思路

### 思路分析

本题的关键在于**逐位反转**并**在不使用 64 位整数的前提下检测溢出**。

**逐位反转：** 通过 `% 10` 取末位，`/ 10` 去掉末位的方式，从原数末尾逐位取出数字，同时构建反转后的数。

**溢出检测：** 由于不能使用 64 位整数，我们需要在执行 `result = result * 10 + pop` 之前预判是否会溢出：

- 正数溢出条件：`result > (2^31 - 1) / 10` 或 (`result === (2^31 - 1) / 10` 且 `pop > 7`)
- 负数溢出条件：`result < -2^31 / 10` 或 (`result === -2^31 / 10` 且 `pop < -8`)

其中 `2^31 - 1 = 2147483647`，`-2^31 = -2147483648`。末位 7 和 -8 来自这两个边界值的末位数字。

## 解法

逐位取模构建反转数，在每一步乘法前预判溢出。

```javascript
/**
 * @param {number} x
 * @return {number}
 */
const reverse = (x) => {
  const INT_MAX = 2147483647;  // 2^31 - 1
  const INT_MIN = -2147483648; // -2^31

  let result = 0;

  while (x !== 0) {
    const pop = x % 10;
    x = Math.trunc(x / 10);

    // 正溢出检测
    if (result > Math.trunc(INT_MAX / 10) ||
        (result === Math.trunc(INT_MAX / 10) && pop > 7)) {
      return 0;
    }
    // 负溢出检测
    if (result < Math.trunc(INT_MIN / 10) ||
        (result === Math.trunc(INT_MIN / 10) && pop < -8)) {
      return 0;
    }

    result = result * 10 + pop;
  }

  return result;
};

// 验证
console.log(reverse(123));        // 321
console.log(reverse(-123));       // -321
console.log(reverse(120));        // 21
console.log(reverse(1534236469)); // 0
console.log(reverse(0));          // 0
console.log(reverse(-2147483648)); // 0
```

- **时间复杂度：** O(log|x|)，即数字的位数，最多 10 次循环（32 位整数）
- **空间复杂度：** O(1)，只使用常数个变量
