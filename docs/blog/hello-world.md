# Hello World

这是我的第一篇博客文章，标志着个人站点的正式上线。

## 为什么搭建这个站点

作为一个开发者，我一直希望有一个属于自己的空间来：

1. **记录学习过程** — 把学到的知识整理成文，加深理解
2. **分享技术思考** — 对技术趋势和实践经验的总结
3. **展示个人作品** — 记录项目的开发过程和技术选型

## 技术选型

经过对比，最终选择了 VitePress 作为站点框架：

| 方案 | 优点 | 缺点 |
|------|------|------|
| Hexo | 博客功能丰富 | 构建速度慢 |
| Hugo | 构建极快 | 模板语法复杂 |
| **VitePress** | **Vue 生态、极快、Markdown 友好** | **博客功能需自行实现** |
